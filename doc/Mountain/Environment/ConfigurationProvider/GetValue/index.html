Configuration value retrieval.

Implements GetConfigurationValue for MountainEnvironment. Reads from the pre-merged ApplicationState::Configuration::GlobalConfiguration cache - no disk I/O on the hot path.

If section is None, the entire merged object is returned. If it is Some("a.b.c"), the key is split on . and the function walks the nested JSON tree one segment at a time, returning Value::Null (not an error) for any missing intermediate or leaf node. This matches VS Code’s behaviour where getConfiguration('a.b').get('c') returns undefined rather than throwing.
