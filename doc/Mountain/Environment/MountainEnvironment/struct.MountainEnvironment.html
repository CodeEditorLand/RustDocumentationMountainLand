Expand description

The concrete Environment for the Mountain application. Primary dependency injection container for the Mountain code editor.

Holds thread-safe references to application state, the async runtime, and the optional Air service client. Provider trait implementations are generated by impl_provider! to enable Requires<T> lookups.

Fields§

§ApplicationHandle: AppHandle<Wry>

Tauri application handle for window and event management.

Thread-safe shared application state machine.

§AirClient: Option<AirServiceClient<Channel>>

Optional Air gRPC client for cloud-based services.

When provided (AirIntegration feature enabled), providers such as SecretProvider and UpdateService can delegate to the Air service.

pub fn SetAirClient(&mut self, AirClient: Option<AirServiceClient<Channel>>)

Replaces the Air gRPC client at runtime.

Call this when the Air service becomes available after the environment was already constructed, or to swap between different Air endpoints. Providers that hold a reference to MountainEnvironment will see the updated client on their next IsAirAvailable call.

Source

pub async fn IsAirAvailable(&self) -> bool

Checks whether the Air service client is configured and available.

Returns true if an Air gRPC client is attached, false otherwise. Note: the actual gRPC health check is deferred until the AirClient wrapper supports mutable references for health-check calls.

async fn ScanExtensionDirectory( &self, path: &PathBuf, ) -> Result<Vec<Value>, CommonError>

Scans a single directory for installed extensions.

Walks each subdirectory looking for package.json. Parsed packages are enriched with an ExtensionLocation field containing the absolute path. Returns all successfully parsed packages; logs warnings for parse/read failures without propagating errors.

fn FindFilesInWorkspace<'life0, 'async_trait>( &'life0 self, IncludePatternDTO: Value, ExcludePatternDTO: Option<Value>, MaxResults: Option<usize>, UseIgnoreFiles: bool, FollowSymlinks: bool, ) -> Pin<Box<dyn Future<Output = Result<Vec<Url>, CommonError>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait,

Finds files in the workspace matching the specified query.

Uses ignore::WalkBuilder::build_parallel() to walk every registered workspace folder on OS threads, respecting .gitignore / .ignore / .git/info/exclude when use_ignore_files is true. Matches each entry’s relative path against IncludePatternDTO (glob), filters out hidden dirs by default, drops to native symlink behaviour when follow_symlinks is false. Returns deduplicated file:// URIs capped at MaxResults (default 10_000).

IncludePatternDTO accepts:

  • String: bare glob ("**/*.rs")
  • { pattern: "..." }: structured form
  • { base, pattern }: VS Code RelativePattern shape (base restricts the walk to that subfolder; falls back to all workspace folders if base doesn’t resolve to a known folder)

ExcludePatternDTO follows the same shapes; null/missing disables the exclude phase. The node_modules, target, dist, .git directories are auto-skipped via WalkBuilder::standard_filters regardless of use_ignore_files to keep walks bounded on monorepos that don’t carry a top-level .gitignore.
