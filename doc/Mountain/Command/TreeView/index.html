Module TreeView

Defines the specific Tauri command handlers for TreeView data requests that originate from the Sky frontend UI.

§Key Features:

  • Tree data retrieval (children, tree items)
  • Tree expansion state management
  • Tree selection handling
  • Drag and drop support
  • Tree view UI interaction
