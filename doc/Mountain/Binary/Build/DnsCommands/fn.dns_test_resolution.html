pub fn dns_test_resolution(
    domain: String,
    dns_port: State<'_, DnsPort>,
) -> Result<bool, String>
Expand description

Tests if a domain resolves correctly.

Performs a quick resolution test and returns a simple success/failure result. Useful for health checks and automated testing.

§Parameters

  • domain - The domain name to test
  • dns_port - Tauri managed state containing the DNS port number

§Returns

Result<bool, String> with true if resolution succeeds, false otherwise, or an error message

§Errors

Returns an error if the test cannot be performed.

§Example (JavaScript)

import { invoke } from '@tauri-apps/api/tauri';

const success = await invoke('dns_test_resolution', {
  domain: 'code.editor.land'
});

if (success) {
  console.log('Resolution test passed');
} else {
  console.log('Resolution test failed');
}
