1//! # Extension Scanner (ExtensionManagement)
2//!
3//! Contains the logic for scanning directories on the filesystem to discover
4//! installed extensions by reading their `package.json` manifests, and for
5//! collecting default configuration values from all discovered extensions.
6//!
7//! ## RESPONSIBILITIES
8//!
9//! ### 1. Extension Discovery
10//! - Scan registered extension paths for valid extensions
11//! - Read and parse `package.json` manifest files
12//! - Validate extension metadata and structure
13//! - Build `ExtensionDescriptionStateDTO` for each discovered extension
14//!
15//! ### 2. Configuration Collection
16//! - Extract default configuration values from extension `contributes.configuration`
17//! - Merge configuration properties from all extensions
18//! - Handle nested configuration objects recursively
19//! - Detect and prevent circular references
20//!
21//! ### 3. Error Handling
22//! - Gracefully handle unreadable directories
23//! - Skip extensions with invalid package.json
24//! - Log warnings for partial scan failures
25//! - Continue scanning even when some paths fail
26//!
27//! ## ARCHITECTURAL ROLE
28//!
29//! The Extension Scanner is part of the **Extension Management** subsystem:
30//!
31//! ```
32//! Startup ──► ScanPaths ──► Scanner ──► Extensions Map ──► ApplicationState
33//! ```
34//!
35//! ### Position in Mountain
36//! - `ExtensionManagement` module: Extension discovery and metadata
37//! - Used during application startup to populate extension registry
38//! - Provides data to `Cocoon` for extension host initialization
39//!
40//! ### Dependencies
41//! - `CommonLibrary::FileSystem`: ReadDirectory and ReadFile effects
42//! - `CommonLibrary::Error::CommonError`: Error handling
43//! - `ApplicationRunTime`: Effect execution
44//! - `ApplicationState`: Extension storage
45//!
46//! ### Dependents
47//! - `InitializationData::ConstructExtensionHostInitializationData`: Sends extensions to Cocoon
48//! - `MountainEnvironment::ScanForExtensions`: Public API for extension scanning
49//! - `ApplicationState::Internal::ScanExtensionsWithRecovery`: Robust scanning wrapper
50//!
51//! ## SCANNING PROCESS
52//!
53//! 1. **Path Resolution**: Get scan paths from `ApplicationState.ExtensionScanPaths`
54//! 2. **Directory Enumeration**: For each path, read directory entries
55//! 3. **Manifest Detection**: Look for `package.json` in each subdirectory
56//! 4. **Parsing**: Deserialize `package.json` into `ExtensionDescriptionStateDTO`
57//! 5. **Augmentation**: Add `ExtensionLocation` (disk path) to metadata
58//! 6. **Storage**: Insert into `ApplicationState.ScannedExtensions` map
59//!
60//! ## CONFIGURATION MERGING
61//!
62//! `CollectDefaultConfigurations()` extracts default values from all extensions'
63//! `contributes.configuration.properties` and merges them into a single JSON object:
64//!
65//! - Handles nested `.` notation (e.g., `editor.fontSize`)
66//! - Recursively processes nested `properties` objects
67//! - Detects circular references to prevent infinite loops
68//! - Returns a flat map of configuration keys to default values
69//!
70//! ## ERROR HANDLING
71//!
72//! - **Directory Read Failures**: Logged as warnings, scanning continues
73//! - **Invalid package.json**: Skipped with warning, scanning continues
74//! - **IO Errors**: Logged, operation continues or fails gracefully
75//!
76//! ## PERFORMANCE
77//!
78//! - Scans are performed asynchronously via `ApplicationRunTime`
79//! - Each directory read is a separate filesystem operation
80//! - Large extension directories may impact startup time
81//! - Consider caching scan results for development workflows
82//!
83//! ## VS CODE REFERENCE
84//!
85//! Borrowed from VS Code's extension management:
86//! - `vs/workbench/services/extensions/common/extensionPoints.ts` - Configuration contribution
87//! - `vs/platform/extensionManagement/common/extensionManagementService.ts` - Extension scanning
88//!
89//! ## TODO
90//!
91//! - [ ] Implement concurrent scanning for multiple paths
92//! - [ ] Add extension scan caching with invalidation
93//! - [ ] Implement extension validation rules (required fields, etc.)
94//! - [ ] Add scan progress reporting for UI feedback
95//! - [ ] Support extension scanning in subdirectories (recursive)
96//!

124/// Scans a single directory for valid extensions.
125///
126/// This function iterates through a given directory, looking for subdirectories
127/// that contain a `package.json` file. It then attempts to parse this file
128/// into an `ExtensionDescriptionStateDTO`.
129pub async fn ScanDirectoryForExtensions(
130	ApplicationHandle:tauri::AppHandle,
131
132	DirectoryPath:PathBuf,
133) -> Result<Vec<ExtensionDescriptionStateDTO>, CommonError> {
134	let RunTime = ApplicationHandle.state::<Arc<ApplicationRunTime>>().inner().clone();
135
136	let mut FoundExtensions = Vec::new();
137
138	let TopLevelEntries = match RunTime.Run(ReadDirectory(DirectoryPath.clone())).await {
139		Ok(entries) => entries,
140
141		Err(error) => {
142			warn!(
143				"[ExtensionScanner] Could not read extension directory '{}': {}. Skipping.",
144				DirectoryPath.display(),
145				error
146			);
147
148			return Ok(Vec::new());
149		},
150	};
151
152	for (EntryName, FileType) in TopLevelEntries {
153		if FileType == FileTypeDTO::Directory {
154			let PotentialExtensionPath = DirectoryPath.join(EntryName);
155
156			let PackageJsonPath = PotentialExtensionPath.join("package.json");
157
158			trace!(
159				"[ExtensionScanner] Checking for package.json in: {}",
160				PotentialExtensionPath.display()
161			);
162
163			if let Ok(PackageJsonContent) = RunTime.Run(ReadFile(PackageJsonPath)).await {
164				match serde_json::from_slice::<ExtensionDescriptionStateDTO>(&PackageJsonContent) {
165					Ok(mut Description) => {
166						// Augment the description with its location on disk.
167						Description.ExtensionLocation =
168							serde_json::to_value(url::Url::from_directory_path(PotentialExtensionPath).unwrap())
169								.unwrap_or(Value::Null);
170
171						FoundExtensions.push(Description);
172					},
173
174					Err(error) => {
175						warn!(
176							"[ExtensionScanner] Failed to parse package.json for extension at '{}': {}",
177							PotentialExtensionPath.display(),
178							error
179						);
180					},
181				}
182			}
183		}
184	}
185
186	Ok(FoundExtensions)
187}

189/// A helper function to extract default configuration values from all
190/// scanned extensions.
191pub fn CollectDefaultConfigurations(State:&ApplicationState) -> Result<Value, CommonError> {
192	let mut MergedDefaults = Map::new();
193
194	let Extensions = State
195		.ScannedExtensions
196		.lock()
197		.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
198
199	for Extension in Extensions.values() {
200		if let Some(contributes) = Extension.Contributes.as_ref().and_then(|v| v.as_object()) {
201			if let Some(configuration) = contributes.get("configuration").and_then(|v| v.as_object()) {
202				if let Some(properties) = configuration.get("properties").and_then(|v| v.as_object()) {
203					// ADVANCED NESTED OBJECT HANDLING: Recursively process configuration properties
204					self::process_configuration_properties(&mut MergedDefaults, "", properties, &mut Vec::new())?;
205				}
206			}
207		}
208	}
209
210	Ok(Value::Object(MergedDefaults))
211}

213/// ADVANCED RECURSIVE CONFIGURATION PROCESSING: Handle nested object structures
214fn process_configuration_properties(
215	merged_defaults:&mut serde_json::Map<String, Value>,
216	current_path:&str,
217	properties:&serde_json::Map<String, Value>,
218	visited_keys:&mut Vec<String>,
219) -> Result<(), CommonError> {
220	for (key, value) in properties {
221		// Build the full path for this property
222		let full_path = if current_path.is_empty() {
223			key.clone()
224		} else {
225			format!("{}.{}", current_path, key)
226		};
227
228		// Check for circular references
229		if visited_keys.contains(&full_path) {
230			return Err(CommonError::Unknown {
231				Description: format!("Circular reference detected in configuration properties: {}", full_path)
232			});
233		}
234
235		visited_keys.push(full_path.clone());
236
237		if let Some(prop_details) = value.as_object() {
238			// Check if this is a nested object structure
239			if let Some(nested_properties) = prop_details.get("properties").and_then(|v| v.as_object()) {
240				// Recursively process nested properties
241				self::process_configuration_properties(merged_defaults, &full_path, nested_properties, visited_keys)?;
242			} else if let Some(default_value) = prop_details.get("default") {
243				// Handle regular property with default value
244				merged_defaults.insert(full_path.clone(), default_value.clone());
245			}
246		}
247
248		// Remove current key from visited keys
249		visited_keys.retain(|k| k != &full_path);
250	}
251
252	Ok(())
