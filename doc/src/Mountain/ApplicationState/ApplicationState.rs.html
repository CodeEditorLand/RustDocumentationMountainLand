1//! # ApplicationState
2//!
3//! Defines the main `ApplicationState` struct, which is the central, shared,
4//! thread-safe state container for the entire Mountain application. It is
5//! managed by Tauri and is accessible to all command handlers and Environment
6//! providers.
7//!
8//! ## RESPONSIBILITIES
9//!
10//! ### 1. State Container
11//! Hold all runtime state for services like:
12//! - Workspace and window state
13//! - Configuration and storage
14//! - Extensions and command registry
15//! - Documents and diagnostic errors
16//! - Terminals, webviews, and tree views
17//! - Source control management state
18//! - Pending UI requests
19//!
20//! ### 2. Thread-Safe Access
21//! - Provide thread-safe access to state via `Arc<Mutex<...>>`
22//! - Ensure proper synchronization for concurrent access
23//! - Handle mutex poisoning gracefully
24//! - Support async operations with proper locking
25//!
26//! ### 3. State Persistence
27//! - Manage memento (state serialization) for crash recovery
28//! - Handle global and workspace-scoped storage
29//! - Provide disk I/O for state loading/saving
30//! - Recover from corrupted state files
31//!
32//! ### 4. Identity Management
33//! - Generate unique provider handles
34//! - Generate unique terminal identifiers
35//! - Generate unique SCM provider handles
36//! - Ensure monotonically increasing IDs
37//!
38//! ### 5. State Recovery
39//! - Detect corrupted state
40//! - Attempt recovery from poisoned locks
41//! - Restore state from disk
42//! - Clear invalid state entries
43//!
44//! ## ARCHITECTURAL ROLE
45//!
46//! The ApplicationState module is the **state management layer** of Mountain:
47//!
48//! ```text
49//! UI ──► Commands ──► ApplicationState (State) ──► Providers/Services
50//!                      │
51//!                      ↓
52//!                   Disk (Persistence)
53//! ```
54//!
55//! ### Design Principles:
56//! 1. **Single Source of Truth**: All state lives in one place
57//! 2. **Thread Safety**: All state is protected by Arc<Mutex<...>>
58//! 3. **Recovery-Oriented**: Comprehensive error handling and recovery
59//! 4. **Type Safety**: Strong typing at all levels
60//! 5. **Observability**: Comprehensive logging for state changes
61//!
62//! ### VS Code Reference:
63//! This module borrows from VS Code's state management patterns in:
64//! - `vs/base/parts/storage/common/storageService.ts` - Storage management
65//! - `vs/workbench/services/environment/common/environmentService.ts` -
66//!   Environment state
67//! - `vs/platform/workspace/common/workspace.ts` - Workspace state
68//! - `vs/workbench/services/extensions/common/extensions.ts` - Extension state
69//!
70//! Key concepts:
71//! - Global vs workspace-scoped storage
72//! - Memento (state serialization) for crash recovery
73//! - Thread-safe state access with proper locking
74//! - State validation and invariants

110// ## VS Code Reference
111//
112// This module borrows from VS Code's state management patterns in:
113//
114// - `vs/platform/storage/common/storageService.ts` - Memento storage
115//   - Global vs workspace-scoped storage separation
116//   - Crash recovery and state persistence
117//   - Key-value storage API
118//

120//   Environment state
121//   - Workspace configuration management
122//   - Window state persistence
123//   - Trust management
124//
125// - `vs/workbench/services/extensions/common/extensions` - Extension state
126//   - Extension registry and metadata
127//   - Language provider management
128//   - Command registration
129//
130// Key patterns adopted:
131// 1. **Memento Pattern**: State is serialized for crash recovery
132// 2. **Repository Pattern**: State access goes through this container
133// 3. **Identity Map**: Track all instances with unique IDs
134// 4. **Observer Pattern**: State changes trigger events
135//
136// ## Data Layout
137//
138// The ApplicationState struct is organized into logical groups:
139//
140// ### Workspace State
141// - `WorkspaceFolders` - Open workspace folders
142// - `WorkspaceConfigurationPath` - Active workspace config file
143// - `IsTrusted` - Workspace security trust status
144// - `WindowState` - Window geometry and state
145// - `ActiveDocumentURI` - Currently active document
146//
147// ### Configuration & Storage
148// - `Configuration` - Merged configuration from all sources
149// - `GlobalMemento` - Global key-value storage
150// - `WorkspaceMemento` - Workspace-scoped storage
151// - Memento paths for persistence
152//
153// ### Extension & Provider Management
154// - `CommandRegistry` - Registered CLI commands
155// - `LanguageProviders` - LSP and other language features
156// - `NextProviderHandle` - Counter for provider IDs
157// - `ScannedExtensions` - Discovered extensions
158// - `EnabledProposedAPIs` - API feature flags
159// - `ExtensionScanPaths` - Where to look for extensions
160//
161// ### Feature-specific State
162// - `DiagnosticsMap` - Compiler/diagnostic errors by owner and resource
163// - `OpenDocuments` - Currently open documents by URI
164// - `OutputChannels` - Output panel channels
165// - `ActiveTerminals` - Terminal instances by ID (nested mutex)
166// - `NextTerminalIdentifier` - Counter for terminal IDs
167// - `ActiveWebviews` - Webview panels by ID
168// - `ActiveCustomDocuments` - Custom editor state
169// - `ActiveStatusBarItems` - Status bar entries
170// - `ActiveTreeViews` - Tree data providers
171// - `SourceControlManagementProviders` - SCM registries
172// - `SourceControlManagementGroups` - SCM resource groups
173// - `SourceControlManagementResources` - SCM resource state
174// - `NextSourceControlManagementProviderHandle` - Counter for SCM IDs
175//
176// ### IPC & UI State
177// - `PendingUserInterfaceRequests` - Ongoing UI interactions (dialogs, etc.)
178//
179// ## Thread Safety
180//
181// All state is protected by `Arc<Mutex<...>>`:
182//
183//```rust
184// pub struct ApplicationState {
185//     pub WorkspaceFolders: Arc<Mutex<Vec<WorkspaceFolderStateDTO>>>,
186//     pub Configuration: Arc<Mutex<MergedConfigurationStateDTO>>,
187//     // ... all fields protected by Arc<Mutex<...>>
188// }
189//```
190// **Access Patterns:**
191// - Lock briefly, copy data needed, release immediately
192// - Use `map_err(MapLockError)` for lock error handling
193// - Avoid nested locks to prevent deadlocks
194// - Prefer read-only copies when possible
195//
196// **Terminal State Note:**
197// Terminals use `Arc<Mutex<...>>>` (double mutex) because:
198// - Outer mutex protects the HashMap of terminals
199// - Inner mutex protects each individual terminal state
200// - Allows concurrent access to different terminals
201//
202// ## State Initialization
203//
204// The `Default` implementation creates a fully initialized state:
205//
206// 1. **Resolve Application Data Directory**:
207//    - Use `dirs::config_dir()` on supported platforms
208//    - Fall back to relative path if unavailable
209//
210// 2. **Ensure Directory Exists**:
211//    - Create if missing
212//    - Log error if creation fails
213//
214// 3. **Load Global Memento**:
215//    - Read from disk if exists
216//    - Default to empty map if not
217//    - Handle corruption gracefully
218//
219// 4. **Initialize All Fields**:
220//    - Empty collections for maps and vectors
221//    - At starting value of 1 for counters
222//    - Default structs for complex state
223//
224// ## Workspace Identification
225//
226// The workspace identifier is generated by `GetWorkspaceIdentifier`:
227//
228// **Priority**:
229// 1. Configuration file name (if workspace open from file)
230// 2. First workspace folder hashed and sanitized
231// 3. "NO_WORKSPACE" if no workspace loaded
232//
233// **Format**: `{folder-name}-{hash[:8]}` or `{config-file-name}`
234//
235// Example: `MyProject-a1b2c3d4` or `settings.json`
236//
237// This identifier is used for:
238// - Workspace memento file naming
239// - Workspace-specific storage
240// - Workspace identification in logs
241//
242// ## Memento Persistence
243//
244// Memento files store state for crash recovery:
245//
246// **Global Memento** (`globalStorage.json`):
247// - Application-wide settings
248// - User preferences
249// - Cross-workspace data
250//
251// **Workspace Memento** (`workspaceStorage/{id}/storage.json`):
252// - Workspace-specific settings
253// - Document state
254// - Per-workspace preferences
255//
256// **Update Flow**:
257// - When workspace opens/changes → `UpdateWorkspaceMementoPathAndReload`
258// - This updates path and reloads from disk
259// - Old workspace state is forgotten
260// - New workspace state is loaded
261//
262// ## Error Handling
263//
264// All functions return `Result<T, CommonError>`:
265//
266// **Error Types**:
267// - `CommonError::StateLockPoisoned` - Mutex poisoned (panic in another thread)
268// - `CommonError::FileSystemIO` - File/directory operations failed
269// - `CommonError::SerializationError` - JSON parsing failed
270// - `CommonError::Unknown` - Uncategorized errors
271//
272// **Recovery Functions**:
273// - `MapLockError` - Convert lock error to CommonError
274// - `MapLockErrorWithRecovery` - Convert with recovery attempt
275// - `SafeStateOperation` - Wrap operation with recovery
276// - `RecoverApplicationState` - Comprehensive recovery
277//
278// **StateOperationResult**:
279// Provides recovery metadata:
280// - `result` - Operation result
281// - `recovery_attempted` - Was recovery tried
282// - `recovery_successful` - Did recovery work
283//
284// ## Recovery Mechanisms
285//
286// ### State Recovery Functions:
287//
288// **`RecoverApplicationState()`**:
289// - Recovers all state components
290// - Calls all sub-recovery functions
291// - Logs comprehensive status
292//
293// **`RecoverGlobalMemento()`**:
294// - Reloads global memento from disk
295// - Resets to empty if corrupted
296//
297// **`RecoverWorkspaceMemento()`**:
298// - Reloads workspace memento from disk
299// - Clears if path is None
300//
301// **`RecoverExtensionState()`**:
302// - Clears potentially corrupted extensions
303// - Removes invalid scan paths
304//
305// **`RecoverDocumentState()`**:
306// - Removes documents that don't exist on disk
307// - Keeps non-file URIs (untitled, virtual)

450/// A helper to map a mutex poison error into a `CommonError`.
451pub fn MapLockError<T>(Error:PoisonError<T>) -> CommonError {
452	CommonError::StateLockPoisoned { Context:Error.to_string() }
453}

455/// A helper to map a mutex poison error with recovery attempt.
456pub fn MapLockErrorWithRecovery<T>(Error:PoisonError<T>, RecoveryContext:&str) -> CommonError {
457	warn!(
458		"[ApplicationState] Attempting recovery from poisoned lock in context: {}",
459		RecoveryContext
460	);
461	CommonError::StateLockPoisoned {
462		Context:format!("{} - Recovery attempted: {}", Error.to_string(), RecoveryContext),
463	}
464}

577	/// Generates a unique, filesystem-safe identifier for the current
578	/// workspace. Returns "NO_WORKSPACE" if no folder or configuration is
579	/// open.
580	pub fn GetWorkspaceIdentifier(&self) -> Result<String, CommonError> {
581		let ConfigurationPathGuard = self
582			.WorkspaceConfigurationPath
583			.lock()
584			.map_err(|e| MapLockErrorWithRecovery(e, "GetWorkspaceIdentifier - ConfigurationPath"))?;
585
586		if let Some(ConfigurationPath) = ConfigurationPathGuard.as_ref() {
587			let FileName = ConfigurationPath.file_name().unwrap_or_default().to_string_lossy().into_owned();
588
589			return Ok(FileName);
590		}
591
592		drop(ConfigurationPathGuard);
593
594		let FoldersGuard = self
595			.WorkspaceFolders
596			.lock()
597			.map_err(|e| MapLockErrorWithRecovery(e, "GetWorkspaceIdentifier - WorkspaceFolders"))?;
598
599		if let Some(FirstFolder) = FoldersGuard.first() {
600			let PathString = FirstFolder.URI.path();
601
602			// Create a more stable hash for the identifier.
603			let Hash = format!("{:x}", md5::compute(PathString));
604
605			let SafeName = FirstFolder.Name.replace(|c:char| !c.is_alphanumeric(), "_");
606
607			return Ok(format!("{}-{}", SafeName, &Hash[..8]));
608		}
609
610		Ok("NO_WORKSPACE".to_string())
611	}

613	/// Safe state operation with automatic recovery
614	pub fn SafeStateOperation<T, F>(&self, operation_name:&str, operation:F) -> StateOperationResult<T>
615	where
616		F: FnOnce() -> Result<T, CommonError>, {
617		let mut recovery_attempted = false;
618		let mut recovery_successful = false;
619
620		match operation() {
621			Ok(result) => StateOperationResult { result:Ok(result), recovery_attempted, recovery_successful },
622			Err(error) => {
623				// Attempt recovery for specific error types
624				if Self::should_attempt_recovery(&error) {
625					recovery_attempted = true;
626					match Self::attempt_state_recovery(&error, operation_name) {
627						Ok(()) => {
628							recovery_successful = true;
629							info!("[ApplicationState] Recovery successful for operation: {}", operation_name);
630							StateOperationResult {
631								result:Err(error), // Original error still returned
632								recovery_attempted,
633								recovery_successful,
634							}
635						},
636						Err(recovery_error) => {
637							warn!(
638								"[ApplicationState] Recovery failed for operation {}: {}",
639								operation_name, recovery_error
640							);
641							StateOperationResult {
642								result:Err(error), // Original error still returned
643								recovery_attempted,
644								recovery_successful,
645							}
646						},
647					}
648				} else {
649					StateOperationResult { result:Err(error), recovery_attempted, recovery_successful }
650				}
651			},
652		}
653	}

655	/// Determine if recovery should be attempted for a given error
656	fn should_attempt_recovery(error:&CommonError) -> bool {
657		match error {
658			CommonError::StateLockPoisoned { .. } => true,
659			CommonError::FileSystemIO { .. } => true,
660			CommonError::SerializationError { .. } => true,
661			_ => false,
662		}
663	}
664
665	/// Attempt state recovery based on error type
666	fn attempt_state_recovery(error:&CommonError, context:&str) -> Result<(), CommonError> {
667		match error {
668			CommonError::StateLockPoisoned { .. } => {
669				// For poisoned locks, we can't do much but log and wait
670				warn!("[ApplicationState] Poisoned lock detected in context: {}", context);
671				// Small delay to allow system to stabilize
672				std::thread::sleep(std::time::Duration::from_millis(100));
673				Ok(())
674			},
675			CommonError::FileSystemIO { Path, .. } => {
676				// Attempt to recreate directories or handle file system issues
677				if let Some(parent) = Path.parent() {
678					if !parent.exists() {
679						std::fs::create_dir_all(parent).map_err(|e| {
680							CommonError::FileSystemIO {
681								Path:parent.to_path_buf(),
682								Description:format!("Failed to create directory during recovery: {}", e),
683							}
684						})?;
685					}
686				}
687				Ok(())
688			},
689			CommonError::SerializationError { .. } => {
690				// For serialization errors, we might need to reset corrupted state
691				warn!(
692					"[ApplicationState] Serialization error detected, state may be corrupted: {}",
693					context
694				);
695				Ok(())
696			},
697			_ => Ok(()),
698		}
699	}

715	/// Updates the path to the workspace memento file and reloads its content
716	/// from disk. This should be called when a workspace is opened or changed.
717	pub fn UpdateWorkspaceMementoPathAndReload(&self, ApplicationDataDirectory:&Path) -> Result<(), CommonError> {
718		let operation_result = self.SafeStateOperation("UpdateWorkspaceMementoPathAndReload", || {
719			let WorkspaceIdentifier = self.GetWorkspaceIdentifier()?;
720
721			let mut PathGuard = self.WorkspaceMementoPath.lock().map_err(|e| {
722				MapLockErrorWithRecovery(e, "UpdateWorkspaceMementoPathAndReload - WorkspaceMementoPath")
723			})?;
724
725			if WorkspaceIdentifier == "NO_WORKSPACE" {
726				if PathGuard.is_some() {
727					*PathGuard = None;
728
729					self.WorkspaceMemento
730						.lock()
731						.map_err(|e| {
732							MapLockErrorWithRecovery(e, "UpdateWorkspaceMementoPathAndReload - WorkspaceMemento")
733						})?
734						.clear();
735				}
736
737				return Ok(());
738			}
739
740			let NewMementoPath =
741				Internal::ResolveMementoStorageFilePath(ApplicationDataDirectory, false, &WorkspaceIdentifier);
742
743			if PathGuard.as_ref() != Some(&NewMementoPath) {
744				if let Some(Parent) = NewMementoPath.parent() {
745					if !Parent.exists() {
746						std::fs::create_dir_all(Parent).map_err(|Error| {
747							CommonError::FileSystemIO { Path:Parent.to_path_buf(), Description:Error.to_string() }
748						})?;
749					}
750				}
751
752				*PathGuard = Some(NewMementoPath.clone());
753
754				let NewMementoContent = Internal::LoadInitialMementoFromDisk(&NewMementoPath);
755
756				*self.WorkspaceMemento.lock().map_err(|e| {
757					MapLockErrorWithRecovery(e, "UpdateWorkspaceMementoPathAndReload - WorkspaceMemento update")
758				})? = NewMementoContent;
759			}
760
761			Ok(())
762		});
763
764		operation_result.result
765	}

823	/// Recover extension state
824	async fn RecoverExtensionState(&self) -> Result<(), CommonError> {
825		debug!("[ApplicationState] Recovering extension state...");
826
827		// Clear potentially corrupted extension state
828		let mut scanned_extensions = self
829			.ScannedExtensions
830			.lock()
831			.map_err(|e| MapLockErrorWithRecovery(e, "RecoverExtensionState - ScannedExtensions"))?;
832
833		scanned_extensions.clear();
834
835		// Reset extension scan paths
836		let mut scan_paths = self
837			.ExtensionScanPaths
838			.lock()
839			.map_err(|e| MapLockErrorWithRecovery(e, "RecoverExtensionState - ExtensionScanPaths"))?;
840
841		// Keep only valid paths that exist
842		scan_paths.retain(|path| path.exists());
843
844		Ok(())
845	}

847	/// Recover document state
848	async fn RecoverDocumentState(&self) -> Result<(), CommonError> {
849		debug!("[ApplicationState] Recovering document state...");
850
851		// Clear potentially corrupted document state
852		let mut open_documents = self
853			.OpenDocuments
854			.lock()
855			.map_err(|e| MapLockErrorWithRecovery(e, "RecoverDocumentState - OpenDocuments"))?;
856
857		// Remove documents that reference non-existent files
858		open_documents.retain(|uri, _doc_state| {
859			if let Ok(parsed_url) = url::Url::parse(uri) {
860				if parsed_url.scheme() == "file" {
861					if let Ok(path) = parsed_url.to_file_path() {
862						return path.exists();
863					}
864				}
865			}
866			true // Keep non-file URIs or invalid URIs
867		});
868		Ok(())
869	}
