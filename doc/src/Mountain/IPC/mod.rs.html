1//! # IPC Module
2//!
3//! Provides the core Inter-Process Communication server for Mountain,
4//! establishing and managing the bidirectional communication bridge between
5//! Mountain's Rust backend and Wind's TypeScript frontend.
6//!
7//! ## RESPONSIBILITIES
8//!
9//! ### Core Responsibilities
10//! - **Message Routing**: Routes incoming messages from Wind to appropriate
11//!   handlers
12//! - **Connection Management**: Maintains connection health and manages
13//!   connection pooling
14//! - **Security Layer**: Implements permissions, encryption, and audit logging
15//! - **Performance Optimization**: Provides message compression and batching
16//!
17//! ## Module Structure
18//!
19//! - [`types`]: Shared types used across the IPC subsystem
20//! - [`compression`]: Message compression utilities for efficient transfer
21//! - [`connection_pool`]: Connection pooling and health monitoring
22//! - [`encryption`]: Secure message channel with AES-256-GCM encryption
23//! - [`permissions`]: Role-based access control (RBAC) and permission
24//!   management
25//! - [`ipc_server`]: Core IPC server implementation
26//! - [`commands`]: Tauri command handlers for IPC operations
27
