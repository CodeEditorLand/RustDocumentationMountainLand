1//! # Wind-Air Commands - Air Daemon Delegation Layer
2//!
3//! **File Responsibilities:**
4//! This module provides the Tauri IPC commands that enable Wind (the TypeScript
5//! frontend) to delegate background operations to Air (the Rust daemon). All
6//! commands use the gRPC-based AirClient for communication and return
7//! structured DTOs or detailed error messages.
8//!
9//! **Architectural Role in Wind-Mountain-Air Connection:**
10//!
11//! The WindAirCommands module forms the delegation layer that:
12//!
13//! 1. **Bridge to Air Daemon:** Provides a Tauri IPC interface to Air's gRPC
14//!    services
15//! 2. **Background Operations:** Offloads long-running tasks from Wind to Air
16//! 3. **Type Translation:** Converts between Tauri JSON and gRPC protobuf
17//!    messages
18//! 4. **Error Handling:** Translates gRPC errors to user-friendly error
19//!    messages
20//! 5. **Connection Management:** Manages Air client lifecycle and reconnections
21//!
22//! **Three-Tier Architecture:**
23//! ```
24//! Wind (Frontend - TypeScript)
25//!   |
26//!   | Tauri IPC Commands
27//!   v
28//! WindAirCommands (Mountain - Rust)
29//!   |
30//!   | gRPC Calls
31//!   v
32//! AirClient (gRPC Client)
33//!   |
34//!   | Network Communication
35//!   v
36//! Air Daemon (gRPC Server)
37//! ```
38//!
39//! **Available Commands (Tauri IPC):**
40//!
41//! **1. Update Management:**
42//! - `CheckForUpdates` - Check for application updates
43//! - `DownloadUpdate` - Download update package
44//! - `ApplyUpdate` - Apply downloaded update
45//!
46//! **2. File Operations:**
47//! - `DownloadFile` - Download any file from URL
48//!
49//! **3. Authentication:**
50//! - `AuthenticateUser` - Authenticate with various providers
51//!
52//! **4. Indexing & Search:**
53//! - `IndexFiles` - Index directory contents
54//! - `SearchFiles` - Search indexed files
55//!
56//! **5. Monitoring:**
57//! - `GetAirStatus` - Get Air daemon status
58//! - `GetAirMetrics` - Get performance & resource metrics
59//!
60//! **Data Transfer Objects (DTOs):**
61//!
62//! **UpdateInfoDTO:**
63//! ```rust
64//! struct UpdateInfoDTO {
65//! 	update_available:bool,
66//! 	version:String,
67//! 	download_url:String,
68//! 	release_notes:String,
69//! }
70//! ```
71//!
72//! **DownloadResultDTO:**
73//! ```rust
74//! struct DownloadResultDTO {
75//! 	success:bool,
76//! 	file_path:String,
77//! 	file_size:u64,
78//! 	checksum:String,
79//! }
80//! ```
81//!
82//! **AuthResponseDTO:**
83//! ```rust
84//! struct AuthResponseDTO {
85//! 	success:bool,
86//! 	token:String,
87//! 	error:Option<String>,
88//! }
89//! ```
90//!
91//! **IndexResultDTO:**
92//! ```rust
93//! struct IndexResultDTO {
94//! 	success:bool,
95//! 	files_indexed:u32,
96//! 	total_size:u64,
97//! }
98//! ```
99//!
100//! **SearchResultsDTO:**
101//! ```rust
102//! struct SearchResultsDTO {
103//! 	results:Vec<FileResultDTO>,
104//! 	total_results:u32,
105//! }
106//! ```
107//!
108//! **FileResultDTO:**
109//! ```rust
110//! struct FileResultDTO {
111//! 	path:String,
112//! 	size:u64,
113//! 	line:Option<u32>,
114//! 	content:Option<String>,
115//! }
116//! ```
117//!
118//! **AirServiceStatusDTO:**
119//! ```rust
120//! struct AirServiceStatusDTO {
121//! 	version:String,
122//! 	uptime_seconds:u64,
123//! 	total_requests:u64,
124//! 	successful_requests:u64,
125//! 	failed_requests:u64,
126//! 	active_requests:u32,
127//! 	healthy:bool,
128//! }
129//! ```
130//!
131//! **AirMetricsDTO:**
132//! ```rust
133//! struct AirMetricsDTO {
134//! 	memory_usage_mb:f64,
135//! 	cpu_usage_percent:f64,
136//! 	average_response_time:f64,
137//! 	disk_usage_mb:f64,
138//! 	network_usage_mbps:f64,
139//! }
140//! ```
141//!
142//! **Command Registration:**
143//!
144//! All commands are registered with Tauri's invoke_handler:
145//!
146//! ```rust
147//! builder.invoke_handler(tauri::generate_handler![
148//! 	CheckForUpdates,
149//! 	DownloadUpdate,
150//! 	ApplyUpdate,
151//! 	DownloadFile,
152//! 	AuthenticateUser,
153//! 	IndexFiles,
154//! 	SearchFiles,
155//! 	GetAirStatus,
156//! 	GetAirMetrics,
157//! ])
158//! ```
159//!
160//! **Client Connection Management:**
161//!
162//! **AirClientWrapper:**
163//! - Wraps the gRPC AirClient
164//! - Manages reconnections
165//! - Default address: `DEFAULT_AIR_SERVER_ADDRESS`
166//!
167//! **Connection Flow:**
168//! ```rust
169//! // 1. Get Air address from config
170//! let air_address = get_air_address(&app_handle)?;
171//!
172//! // 2. Create or reuse client
173//! let client = get_or_create_air_client(&app_handle, air_address).await?;
174//!
175//! // 3. Call Air's gRPC method
176//! let response = client.CheckForUpdates(request).await?;
177//!
178//! // 4. Check for errors
179//! if !response.error.is_empty() {
180//!     return Err(response.error);
181//! }
182//!
183//! // 5. Convert to DTO
184//! let result = UpdateInfoDTO { ... };
185//! ```
186//!
187//! **Error Handling Strategy:**
188//!
189//! **gRPC Errors:**
190//! - Catch all gRPC errors
191//! - Translate to user-friendly messages
192//! - Include context about what operation failed
193//!
194//! **Response Errors:**
195//! - Check `response.error` field
196//! - Return error instead of DTO if present
197//! - Preserve original error message
198//!
199//! **Client Errors:**
200//! - Connection failures -> "Failed to connect to Air daemon"
201//! - Timeout errors -> "Operation timed out"
202//! - Parse errors -> "Failed to parse response"
203//!
204//! **Usage Examples from Wind:**
205//!
206//! **Check for Updates:**
207//! ```typescript
208//! const updates = await invoke('CheckForUpdates', {
209//!     currentVersion: '1.0.0',
210//!     channel: 'stable'
211//! });
212//!
213//! if (updates.updateAvailable) {
214//!     console.log(`New version: ${updates.version}`);
215//! }
216//! ```
217//!
218//! **Download Update:**
219//! ```typescript
220//! const result = await invoke('DownloadUpdate', {
221//!     url: 'https://example.com/update.zip',
222//!     destination: '/tmp/update.zip',
223//!     checksum: 'abc123...'
224//! });
225//!
226//! if (result.success) {
227//!     console.log(`Downloaded: ${result.filePath}`);
228//! }
229//! ```
230//!
231//! **Authenticate:**
232//! ```typescript
233//! const auth = await invoke('AuthenticateUser', {
234//!     username: 'user@example.com',
235//!     password: 'secret',
236//!     provider: 'github'
237//! });
238//!
239//! if (auth.success) {
240//!     localStorage.setItem('token', auth.token);
241//! }
242//! ```
243//!
244//! **Index Files:**
245//! ```typescript
246//! const indexResult = await invoke('IndexFiles', {
247//!     path: '/project',
248//!     patterns: ['*.ts', '*.rs'],
249//!     excludePatterns: ['node_modules', 'target'],
250//!     maxDepth: 10
251//! });
252//!
253//! console.log(`Indexed ${indexResult.filesIndexed} files`);
254//! ```
255//!
256//! **Search Files:**
257//! ```typescript
258//! const searchResults = await invoke('SearchFiles', {
259//!     query: 'TODO:',
260//!     indexId: '/project',
261//!     maxResults: 100
262//! });
263//!
264//! for (const file of searchResults.results) {
265//!     console.log(`${file.path}:${file.line} - ${file.content}`);
266//! }
267//! ```
268//!
269//! **Integration with Other Modules:**
270//!
271//! **TauriIPCServer:**
272//! - Commands registered in same invoke handler
273//! - Both provide Tauri IPC interfaces
274//!
275//! **Configuration:**
276//! - Air address configurable via Mountain settings
277//! - Uses default if not specified
278//!
279//! **StatusReporter:**
280//! - Air status can be reported to Sky
281//! - Metrics collected for monitoring
282//!
283//! **Security Considerations:**
284//!
285//! - Passwords never logged
286//! - Checksums verified for downloads
287//! - File paths validated
288//! - Provider authentication handled securely by Air
289//!
290//! **Performance Considerations:**
291//!
292//! - Client connections are created fresh each call (current implementation)
293//! - Could cache clients for better performance in production
294//! - Large file downloads streamed via Air
295//! - Indexing operations run asynchronously in Air

384/// Air Client - Wrapper for the gRPC client connection to Air daemon
385#[derive(Debug, Clone)]
386pub struct AirClientWrapper {
387	client:AirClientType,
388}
389
390impl AirClientWrapper {
391	/// Create a new AirClient connected to the Air daemon
392	pub async fn new(address:String) -> Result<Self, String> {
393		debug!("[WindAirCommands] Connecting to Air daemon at: {}", address);
394
395		let client = AirClientType::new(&address)
396			.await
397			.map_err(|e| format!("Failed to connect to Air daemon: {}", e))?;
398
399		info!("[WindAirCommands] Successfully connected to Air daemon");
400		Ok(Self { client })
401	}
402
403	/// Reconnect to Air daemon
404	pub async fn reconnect(&mut self, address:String) -> Result<(), String> {
405		debug!("[WindAirCommands] Reconnecting to Air daemon at: {}", address);
406
407		let client = AirClientType::new(&address)
408			.await
409			.map_err(|e| format!("Failed to reconnect to Air daemon: {}", e))?;
410
411		self.client = client;
412		info!("[WindAirCommands] Successfully reconnected to Air daemon");
413		Ok(())
414	}
415}

421/// Command: Check for Updates
422///
423/// Checks if a newer version of the application is available.
424/// Delegates to Air's update checking service.
425///
426/// # Arguments
427/// * `app_handle` - Tauri application handle
428/// * `current_version` - Current application version
429/// * `channel` - Update channel ("stable", "beta", "nightly")
430///
431/// # Returns
432/// `UpdateInfoDTO` with update information or error message
433#[tauri::command]
434pub async fn CheckForUpdates(current_version:Option<String>, channel:Option<String>) -> Result<UpdateInfoDTO, String> {
435	debug!(
436		"[WindAirCommands] CheckForUpdates called with version: {:?}, channel: {:?}",
437		current_version, channel
438	);
439
440	// Get the Air client from app state or configuration
441	let air_address = get_air_address()?;
442	let client = get_or_create_air_client(air_address).await?;
443
444	// Build the request
445	let request = UpdateCheckRequest {
446		request_id:uuid::Uuid::new_v4().to_string(),
447		current_version:current_version.unwrap_or_else(|| env!("CARGO_PKG_VERSION").to_string()),
448		channel:channel.unwrap_or_else(|| "stable".to_string()),
449	};
450
451	// Delegate to Air via gRPC
452	let response = client
453		.CheckForUpdates(request)
454		.await
455		.map_err(|e| format!("Update check failed: {}", e))?;
456
457	// Check for errors in the response
458	if !response.error.is_empty() {
459		return Err(response.error);
460	}
461
462	let result = UpdateInfoDTO {
463		update_available:response.update_available,
464		version:response.version,
465		download_url:response.download_url,
466		release_notes:response.release_notes,
467	};
468
469	info!(
470		"[WindAirCommands] Update check completed: available={}",
471		result.update_available
472	);
473	Ok(result)
474}

487/// # Returns

490pub async fn DownloadUpdate(
491	url:String,
492	destination:String,

495	debug!("[WindAirCommands] DownloadUpdate called: {} -> {}", url, destination);

499
500	let request = DownloadRequest {
501		request_id:uuid::Uuid::new_v4().to_string(),
502		url,
503		destination_path:destination,
504		checksum:checksum.unwrap_or_default(),
505		headers:Default::default(),
506	};
507
508	let response = client
509		.DownloadFile(request)
510		.await
511		.map_err(|e| format!("Update download failed: {}", e))?;
512
513	if !response.error.is_empty() {
514		return Err(response.error);
515	}
516
517	let result = DownloadResultDTO {
518		success:response.success,
519		file_path:response.file_path,
520		file_size:response.file_size,
521		checksum:response.checksum,
522	};
523
524	info!("[WindAirCommands] Update download completed: success={}", result.success);
525	Ok(result)
526}

614///
615/// Authenticates a user with the specified provider.
616/// Delegates to Air's authentication service.
617///
618/// # Arguments
619/// * `app_handle` - Tauri application handle
620/// * `username` - User's username/email
621/// * `password` - User's password (or auth token)
622/// * `provider` - Auth provider ("github", "gitlab", "microsoft", etc.)
623///
624/// # Returns
625/// `AuthResponseDTO` with authentication token
626#[tauri::command]
627pub async fn AuthenticateUser(username:String, password:String, provider:String) -> Result<AuthResponseDTO, String> {
628	debug!("[WindAirCommands] AuthenticateUser called: {} via {}", username, provider);
629
630	let air_address = get_air_address()?;
631	let client = get_or_create_air_client(air_address).await?;
632
633	let request = AuthenticationRequest {
634		request_id:uuid::Uuid::new_v4().to_string(),
635		provider,
636		credentials:serde_json::json!({"username": username, "password": password}),
637	};
638
639	let response = client
640		.AuthenticateUser(request)
641		.await
642		.map_err(|e| format!("Authentication failed: {}", e))?;
643
644	if !response.success && !response.error.is_empty() {
645		return Err(response.error);
646	}
647
648	let result = AuthResponseDTO {
649		success:response.success,
650		token:response.token,
651		error:if response.error.is_empty() { None } else { Some(response.error) },
652	};
653
654	info!("[WindAirCommands] Authentication completed: success={}", result.success);
655	Ok(result)
656}

714/// # Arguments
715/// * `app_handle` - Tauri application handle
716/// * `query` - Search query string
717/// * `index_id` - Index identifier (or path for backward compatibility)
718/// * `max_results` - Maximum number of results to return
719///
720/// # Returns
721/// `SearchResultsDTO` with matching files
722#[tauri::command]
723pub async fn SearchFiles(
724	query:String,
725	file_patterns:Vec<String>,
726	max_results:Option<u32>,
727) -> Result<SearchResultsDTO, String> {
728	debug!(
729		"[WindAirCommands] SearchFiles called: query={}, patterns={:?}",
730		query, file_patterns
731	);
732
733	let air_address = get_air_address()?;
734	let client = get_or_create_air_client(air_address).await?;
735
736	let request = SearchRequest {
737		request_id:uuid::Uuid::new_v4().to_string(),
738		query,
739		file_patterns,
740		max_results:max_results.unwrap_or(100),
741	};
742
743	let response = client
744		.SearchFiles(request)
745		.await
746		.map_err(|e| format!("File search failed: {}", e))?;
747
748	if !response.error.is_empty() {
749		return Err(response.error);
750	}
751
752	let results:Vec<FileResultDTO> = response
753		.results
754		.into_iter()
755		.map(|r| FileResultDTO { path:r.path, size:r.size, line:r.line, content:r.content })
756		.collect();
757
758	let result = SearchResultsDTO { results, total_results:response.total_results };
759
760	info!("[WindAirCommands] File search completed: {} results", result.total_results);
761	Ok(result)

769/// # Arguments
770/// * `app_handle` - Tauri application handle
771///
772/// # Returns
773/// `AirServiceStatusDTO` with service status information
774#[tauri::command]
775pub async fn GetAirStatus() -> Result<AirServiceStatusDTO, String> {
776	debug!("[WindAirCommands] GetAirStatus called");
777
778	let air_address = get_air_address()?;
779	let client = get_or_create_air_client(air_address).await?;
780
781	let request = StatusRequest { request_id:uuid::Uuid::new_v4().to_string() };
782
783	let response = client
784		.GetStatus(request)
785		.await
786		.map_err(|e| format!("Failed to get Air status: {}", e))?;
787
788	// TODO: Implement HealthCheck method in AirClient
789	let healthy = response.uptime_seconds > 0;
790
791	let result = AirServiceStatusDTO {
792		version:response.version,
793		uptime_seconds:response.uptime_seconds,
794		total_requests:response.total_requests,
795		successful_requests:response.successful_requests,
796		failed_requests:response.failed_requests,
797		active_requests:response.active_requests,
798		healthy,
799	};
800
801	debug!(
802		"[WindAirCommands] Air status retrieved: version={}, healthy={}",
803		result.version, result.healthy
804	);
805	Ok(result)
806}

808/// Command: Get Air Metrics
809///
810/// Retrieves performance and resource metrics from Air.
811/// Delegates to Air's metrics service.
812///
813/// # Arguments
814/// * `app_handle` - Tauri application handle
815/// * `metric_type` - Type of metrics ("all", "performance", "resources",
816///   "requests")
817///
818/// # Returns
819/// `AirMetricsDTO` with metrics data
820#[tauri::command]
821pub async fn GetAirMetrics(metric_type:Option<String>) -> Result<AirMetricsDTO, String> {
822	debug!("[WindAirCommands] GetAirMetrics called with type: {:?}", metric_type);
823
824	let air_address = get_air_address()?;
825	let client = get_or_create_air_client(air_address).await?;
826
827	let request = MetricsRequest { request_id:uuid::Uuid::new_v4().to_string(), metric_type };
828
829	let response = client
830		.GetMetrics(request)
831		.await
832		.map_err(|e| format!("Failed to get Air metrics: {}", e))?;
833
834	let result = AirMetricsDTO {
835		memory_usage_mb:response.metrics.memory_usage_mb,
836		cpu_usage_percent:response.metrics.cpu_usage_percent,
837		average_response_time:response.metrics.average_response_time,
838		disk_usage_mb:response.metrics.disk_usage_mb,
839		network_usage_mbps:response.metrics.network_usage_mbps,
840	};
841
842	debug!("[WindAirCommands] Air metrics retrieved");
843	Ok(result)
844}
