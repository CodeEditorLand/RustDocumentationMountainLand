1//! # StatusBarProvider (Environment)
2//!
3//! Implements the `StatusBarProvider` trait for `MountainEnvironment`, managing
4//! the creation, update, and removal of status bar items at the bottom of the
5//! application window.
6//!
7//! ## RESPONSIBILITIES
8//!
9//! ### 1. Status Bar Item Management
10//! - Create status bar items with unique identifiers
11//! - Update item text, tooltip, and visibility
12//! - Remove items when no longer needed
13//! - Manage item lifecycle from creation to disposal
14//!
15//! ### 2. Status Bar Organization
16//! - Support left and right alignment groups
17//! - Implement priority ordering within alignment groups
18//! - Handle item visibility and spacing
19//! - Manage item ordering and z-index
20//!
21//! ### 3. Dynamic Content
22//! - Support text updates in real-time (e.g., git branch, encoding)
23//! - Handle command association on click
24//! - Support color and style customization
25//! - Enable tooltip resolution via callbacks
26//!
27//! ### 4. Extension Integration
28//! - Allow extensions to contribute status bar items
29//! - Route status bar commands to extension handlers
30//! - Manage extension-provided item lifecycle
31//! - Coordinate with Cocoon sidecar for extension UI
32//!
33//! ## ARCHITECTURAL ROLE
34//!
35//! StatusBarProvider is the **status bar orchestrator**:
36//!
37//! ```text
38//! Provider ──► Create/Update ──► Status Bar UI (Sky)
39//!       │                            │
40//!       └─► Command ──► DispatchLogic ──► Handler
41//! ```
42//!
43//! ### Position in Mountain
44//! - `Environment` module: UI capability provider
45//! - Implements `CommonLibrary::StatusBar::StatusBarProvider` trait
46//! - Accessible via `Environment.Require<dyn StatusBarProvider>()`
47//!
48//! ### Status Bar State
49//! - `ApplicationState.ActiveStatusBarItems`: HashMap<String, StatusBarEntryDTO>
50//!   - Key: Status bar item ID (unique)
51//!   - Value: StatusBarEntryDTO with text, tooltip, alignment, priority, etc.
52//!
53//! ### UI Representation
54//! - Items displayed horizontally at bottom of window
55//! - Left-aligned items: From left to right by descending priority
56//! - Right-aligned items: From right to left by descending priority
57//! - Items can be shown/hidden dynamically
58//!
59//! ### Dependencies
60//! - `ApplicationState`: Status bar item storage
61//! - `IPCProvider`: To send updates to Sky frontend
62//! - `CommandExecutor`: For status bar item command execution
63//! - `Log`: Status bar change logging
64//!
65//! ### Dependents
66//! - Extensions: Create status bar items via `createStatusBarEntry`
67//! - Built-in commands: Show encoding, line endings, git branch, etc.
68//! - `Binary::Main`: Initialize status bar during startup
69//! - `DispatchLogic`: Route status bar command invocations
70//!
71//! ## STATUS BAR ITEM PROPERTIES
72//!
73//! A `StatusBarEntryDTO` includes:
74//! - `ID`: Unique identifier for the item
75//! - `Text`: Display text (supports `$` variables like `$(line)`)
76//! - `Tooltip`: Hover tooltip (static or dynamic via callback)
77//! - `Alignment`: Left or Right
78//! - `Priority`: Ordering within alignment group (higher = more left)
79//! - `Command`: Command ID to execute on click
80//! - `IsVisible`: Show/hide flag
81//! - `Color`: Optional text color override
82//! - `BackgroundColor`: Optional background color
83//!
84//! ## PRIORITY SYSTEM
85//!
86//! Priority determines horizontal ordering within an alignment group:
87//! - **Higher priority** items appear **to the left** (for left-aligned)
88//! - **Higher priority** items appear **to the right** (for right-aligned)
89//! - Default priorities: 0-100 range
90//! - Extension items typically use priorities 0-50
91//! - Built-in items use priorities 50-100
92//!
93//! Example left-aligned ordering (high to low):
94//! ```
95//! [Encoding: UTF-8] [Line: LF] [Git: main*] [Branch: main]
96//!   Priority 100     80          70           60
97//! ```
98//!
99//! ## DYNAMIC TOOLTIP RESOLUTION
100//!
101//! Tooltips can be static strings or dynamic via a sidecar callback:
102//! 1. Item created with `tooltip: "Loading..."` and `resolve_tooltip: true`
103//! 2. When user hovers, Sky requests tooltip from Mountain
104//! 3. Mountain calls extension's `onDidHover` callback (via IPC)
105//! 4. Extension returns dynamic tooltip content
106//! 5. Sky updates tooltip display
107//!
108//! ## ERROR HANDLING
109//!
110//! - Duplicate ID: `CommonError::InvalidArgument` (or replace existing)
111//! - Invalid alignment: Default to left
112//! - Missing command: Log warning, item still created
113//! - IPC failures: Log error, item may not update in UI
114//!
115//! ## PERFORMANCE
116//!
117//! - Status bar updates are batched and sent via IPC efficiently
118//! - Item lookup by ID is O(1) via HashMap
119//! - Priority ordering uses sorting (acceptable for small item counts)
120//! - Dynamic tooltips incur IPC round-trip (cache if频繁)
121//!
122//! ## VS CODE REFERENCE
123//!
124//! Patterns from VS Code:
125//! - `vs/workbench/api/common/extHostStatusBar.ts` - Extension API
126//! - `vs/platform/statusbar/common/statusbar.ts` - Status bar service
127//! - `vs/workbench/services/statusbar/common/statusbar.ts` - Implementation

195//! # StatusBarProvider Implementation
196//!
197//! Implements the `StatusBarProvider` trait for the `MountainEnvironment`. This
198//! provider handles creating, updating, and removing status bar items, and
199//! orchestrates communication between the `Cocoon` sidecar and the `Sky`
200//! frontend.
201
202use std::sync::Arc;
203
204use CommonLibrary::{
205	Environment::Requires::Requires,
206	Error::CommonError::CommonError,
207	IPC::{DTO::ProxyTarget::ProxyTarget, IPCProvider::IPCProvider},
208	StatusBar::{DTO::StatusBarEntryDTO::StatusBarEntryDTO, StatusBarProvider::StatusBarProvider},
209};
210use async_trait::async_trait;
211use log::info;
212use serde_json::{Value, json};
213use tauri::Emitter;
214
215use super::{MountainEnvironment::MountainEnvironment, Utility};
216
217#[async_trait]
218impl StatusBarProvider for MountainEnvironment {
219	/// Creates a new status bar entry or updates an existing one.
220	async fn SetStatusBarEntry(&self, Entry:StatusBarEntryDTO) -> Result<(), CommonError> {
221		info!("[StatusBarProvider] Setting entry: {}", Entry.EntryIdentifier);
222
223		let mut ItemsGuard = self
224			.ApplicationState
225			.ActiveStatusBarItems
226			.lock()
227			.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
228
229		ItemsGuard.insert(Entry.EntryIdentifier.clone(), Entry.clone());
230
231		drop(ItemsGuard);
232
233		self.ApplicationHandle
234			.emit("sky://statusbar/set-entry", Entry)
235			.map_err(|Error| CommonError::UserInterfaceInteraction { Reason:Error.to_string() })
236	}
237
238	/// Removes a status bar item from the UI.
239	async fn DisposeStatusBarEntry(&self, EntryIdentifier:String) -> Result<(), CommonError> {
240		info!("[StatusBarProvider] Disposing entry: {}", EntryIdentifier);
241
242		self.ApplicationState
243			.ActiveStatusBarItems
244			.lock()
245			.map_err(Utility::MapApplicationStateLockErrorToCommonError)?
246			.remove(&EntryIdentifier);
247
248		self.ApplicationHandle
249			.emit("sky://statusbar/dispose-entry", json!({ "EntryIdentifier": EntryIdentifier }))
250			.map_err(|Error| CommonError::UserInterfaceInteraction { Reason:Error.to_string() })
251	}
252
253	/// Shows a temporary message in the status bar.
254	async fn SetStatusBarMessage(&self, MessageIdentifier:String, Text:String) -> Result<(), CommonError> {
255		info!("[StatusBarProvider] Setting status message '{}': {}", MessageIdentifier, Text);
256
257		self.ApplicationHandle
258			.emit("sky://statusbar/set-message", json!({ "id": MessageIdentifier, "text": Text }))
259			.map_err(|Error| CommonError::UserInterfaceInteraction { Reason:Error.to_string() })
260	}
261
262	/// Disposes of a temporary status bar message.
263	async fn DisposeStatusBarMessage(&self, MessageIdentifier:String) -> Result<(), CommonError> {
264		info!("[StatusBarProvider] Disposing status message '{}'", MessageIdentifier);
265
266		self.ApplicationHandle
267			.emit("sky://statusbar/dispose-message", json!({ "id": MessageIdentifier }))
268			.map_err(|Error| CommonError::UserInterfaceInteraction { Reason:Error.to_string() })
269	}
270
271	/// Resolves a dynamic tooltip by making a reverse call to the extension
272	/// host.
273	async fn ProvideTooltip(&self, EntryIdentifier:String) -> Result<Option<Value>, CommonError> {
274		info!("[StatusBarProvider] Providing dynamic tooltip for entry: {}", EntryIdentifier);
275
276		let IPCProvider:Arc<dyn IPCProvider> = self.Require();
277
278		// This is a "reverse" call, where the host needs data from the sidecar.
279		let RPCMethod = format!("{}$ProvideStatusbarTooltip", ProxyTarget::ExtHostStatusBar.GetTargetPrefix());
280
281		let RPCResponse = IPCProvider
282			.SendRequestToSideCar("cocoon-main".to_string(), RPCMethod, json!([EntryIdentifier]), 5000)
283			.await?;
284
285		// If the response is null or fails to parse, we gracefully return None.
286		Ok(serde_json::from_value(RPCResponse).unwrap_or(None))
287	}
288}
