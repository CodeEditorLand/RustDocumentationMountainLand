1//! # WebviewProvider (Environment)
2//!
3//! Implements the `WebviewProvider` trait for `MountainEnvironment`, providing
4//! the core logic for creating, managing, and securing Webview panels - the
5//! embedded browser-based UI components that power many extension features.
6//!
7//! ## RESPONSIBILITIES
8//!
9//! ### 1. Webview Panel Creation
10//! - Create webview windows with proper configuration
11//! - Set up webview content (HTML, CSS, JavaScript)
12//! - Configure webview security (CSP, sandbox, permissions)
13//! - Initialize webview lifecycle and event handlers
14//!
15//! ### 2. Webview Management
16//! - Track active webview instances in `ApplicationState.ActiveWebviews`
17//! - Handle webview focus and visibility changes
18//! - Support webview window positioning and sizing
19//! - Manage webview disposal and cleanup
20//!
21//! ### 3. Secure Message Passing
22//! - Establish bidirectional IPC between host and webview
23//! - Validate and route messages between webview and extension sidecar
24//! - Implement message authentication and authorization
25//! - Prevent cross-origin security vulnerabilities
26//!
27//! ### 4. State Persistence
28//! - Save webview state (position, size, content) to `ApplicationState`
29//! - Restore webview state when reopening
30//! - Persist webview settings across sessions
31//! - Handle webview state serialization/deserialization
32//!
33//! ### 5. Content Security
34//! - Enforce content security policy (CSP)
35//! - Sandbox webview content to prevent escape
36//! - Validate webview URLs and origins
37//! - Protect against XSS and injection attacks
38//!
39//! ## ARCHITECTURAL ROLE
40//!
41//! WebviewProvider is the **webview lifecycle manager**:
42//!
43//! ```text
44//! Extension ──► CreateWebview ──► WebviewProvider ──► Tauri WebviewWindow
45//!                     │                              │
46//!                     └─► IPC ──► Cocoon ◄───────────┘
47//! ```
48//!
49//! ### Position in Mountain
50//! - `Environment` module: Web content capability provider
51//! - Implements `CommonLibrary::Webview::WebviewProvider` trait
52//! - Accessible via `Environment.Require<dyn WebviewProvider>()`
53//!
54//! ### Webview Types
55//! - **Panel**: Sidebar or panel webview (non-floating)
56//! - **Editor**: Webview as custom editor (full editor area)
57//! - **Modal**: Modal dialog webview (centered, blocks interaction)
58//! - **Widget**: Small embedded webview (e.g., diff viewer)
59//!
60//! ### Webview Lifecycle
61//! 1. **Create**: Extension calls `CreateWebview` with options
62//! 2. **Initialize**: Provider builds webview window, sets up event handlers
63//! 3. **Load Content**: HTML loaded, scripts execute
64//! 4. **Ready**: `onDidBecomeVisible` / `onDidBecomeHidden` events
65//! 5. **Dispose**: When closed, cleanup state and resources
66//!
67//! ### Dependencies
68//! - `Tauri`: `WebviewWindowBuilder` for webview creation
69//! - `ApplicationState`: Webview state tracking
70//! - `IPCProvider`: For extension-side communication
71//! - `Log`: Webview lifecycle logging
72//!
73//! ### Dependents
74//! - Extensions: Create webviews via `registerWebviewPanelProvider`
75//! - `Binary::Main`: Webview window creation during startup
76//! - `DispatchLogic::MountainWebviewPostMessageFromGuest`: Webview → host messages
77//! - UI components: Webview panel management
78//!
79//! ## WEBVIEW OPTIONS
80//!
81//! `WebviewContentOptionsDTO` controls webview behavior:
82//! - `Handle`: Unique UUID for this webview
83//! - `ViewType`: Extension-defined type identifier
84//! - `Title`: Panel title
85//! - `ContentOptions`: HTML, base URL, scripts, styles
86//! - `PanelOptions`: Size, position, enable/disable features
87//! - `SideCarIdentifier`: Host extension sidecar
88//! - `ExtensionIdentifier`: Owning extension ID
89//! - `IsActive`, `IsVisible`: State flags
90//!
91//! ## SECURITY CONSIDERATIONS
92//!
93//! - **Content Security Policy**: Default CSP restricts external resources
94//! - **Sandbox**: Webview runs in sandboxed process (no Node.js)
95//! - **Message Validation**: All postMessage() calls validated
96//! - **Origin Checking**: Verify message source matches expected webview
97//! - **Permission Management**: Granular permissions for APIs (geolocation, etc.)
98//!
99//! ## MESSAGE FLOW
100//!
101//! 1. Extension → Host: `webview.postMessage({ command: "..." })`
102//! 2. Provider receives via `MountainWebviewPostMessageFromGuest` command
103//! 3. Provider forwards to extension via IPC (`SendNotificationToSideCar`)
104//! 4. Extension processes and responds
105//! 5. Host → Extension: `ipc.postMessage({ command: "..." })`
106//! 6. Extension receives via `onDidReceiveMessage` event
107//!
108//! ## PERFORMANCE
109//!
110//! - Webview creation is relatively expensive (new browser context)
111//! - Reuse webviews when possible instead of creating new ones
112//! - Consider lazy loading for rarely used webviews
113//! - Memory usage: ~50-100MB per webview (depending on content)
114//! - Use `Dispose` promptly when webview no longer needed
115//!
116//! ## ERROR HANDLING
117//!
118//! - Webview creation failure: `CommonError::WebviewCreationFailed`
119//! - IPC communication failure: `CommonError::IPCError`
120//! - Invalid webview options: `CommonError::InvalidArgument`
121//! - Webview already exists: `CommonError::DuplicateWebview`
122//!
123//! ## VS CODE REFERENCE
124//!
125//! Patterns from VS Code:
126//! - `vs/workbench/contrib/webview/browser/webviewService.ts` - Webview service
127//! - `vs/workbench/contrib/webview/common/webview.ts` - Webview data model
128//! - `vs/workbench/api/browser/mainThreadWebview.ts` - Extension API
129//!

204	/// Creates a new Webview panel with proper security isolation.
205	async fn CreateWebviewPanel(
206		&self,
207		ExtensionDataValue:Value,
208		ViewType:String,
209		Title:String,
210		_ShowOptionsValue:Value,
211		PanelOptionsValue:Value,
212		ContentOptionsValue:Value,
213	) -> Result<String, CommonError> {
214		let Handle = Uuid::new_v4().to_string();
215
216		info!(
217			"[WebviewProvider] Creating WebviewPanel with handle: {}, viewType: {}",
218			Handle, ViewType
219		);
220
221		// Parse content options to ensure security settings
222		let ContentOptions = serde_json::from_value(ContentOptionsValue.clone()).map_err(|Error| {
223			CommonError::InvalidArgument { ArgumentName:"ContentOptions".into(), Reason:Error.to_string() }
224		})?;
225
226		let State = WebviewStateDTO {
227			Handle:Handle.clone(),
228			ViewType:ViewType.clone(),
229			Title:Title.clone(),
230			ContentOptions,
231			PanelOptions:PanelOptionsValue.clone(),
232			SideCarIdentifier:"cocoon-main".to_string(),
233			ExtensionIdentifier:ExtensionDataValue
234				.get("id")
235				.and_then(|v| v.as_str())
236				.unwrap_or_default()
237				.to_string(),
238			IsActive:true,
239			IsVisible:true,
240		};
241
242		// Store the initial state with lifecycle state
243		{
244			let mut WebviewGuard = self
245				.ApplicationState
246				.ActiveWebviews
247				.lock()
248				.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
249
250			WebviewGuard.insert(Handle.clone(), State);
251		}
252
253		// Create a new Tauri window for this webview with security settings
254		let TitleClone = Title.clone();
255		WebviewWindowBuilder::new(
256			&self.ApplicationHandle,
257			&Handle,
258			tauri::WebviewUrl::App("WebviewHost.html".into()),
259		)
260		.title(Title)
261		.initialization_script(&format!(
262			"window.__WEBVIEW_INITIAL_STATE__ = {};",
263			json!({
264				"Handle": Handle,
265				"ViewType": ViewType,
266				"Title": TitleClone
267			})
268		))
269		.build()
270		.map_err(|Error| {
271			error!("[WebviewProvider] Failed to create Webview window: {}", Error);
272			CommonError::UserInterfaceInteraction { Reason:Error.to_string() }
273		})?;
274
275		// Setup message listener for this Webview
276		Self::SetupWebviewMessageListener(self, Handle.clone()).await?;
277
278		// Notify frontend about Webview creation
279		self.ApplicationHandle
280			.emit(
281				"sky://webview/created",
282				json!({ "Handle": Handle.clone(), "ViewType": ViewType.clone(), "Title": TitleClone }),
283			)
284			.map_err(|Error| {
285				CommonError::IPCError { Description:format!("Failed to emit Webview creation event: {}", Error) }
286			})?;
287
288		Ok(Handle)
289	}

291	/// Disposes a Webview panel and cleans up all associated resources.
292	async fn DisposeWebviewPanel(&self, Handle:String) -> Result<(), CommonError> {
293		info!("[WebviewProvider] Disposing WebviewPanel: {}", Handle);
294
295		// Remove message listener
296		Self::RemoveWebviewMessageListener(self, &Handle).await;
297
298		// Close the window
299		if let Some(WebviewWindow) = self.ApplicationHandle.get_webview_window(&Handle) {
300			if let Err(Error) = WebviewWindow.close() {
301				warn!("[WebviewProvider] Failed to close Webview window: {}", Error);
302			}
303		}
304
305		// Remove state
306		self.ApplicationState
307			.ActiveWebviews
308			.lock()
309			.map_err(Utility::MapApplicationStateLockErrorToCommonError)?
310			.remove(&Handle);
311
312		// Notify frontend about Webview disposal
313		self.ApplicationHandle
314			.emit("sky://webview/disposed", json!({ "Handle": Handle }))
315			.map_err(|Error| {
316				CommonError::IPCError { Description:format!("Failed to emit Webview disposal event: {}", Error) }
317			})?;
318
319		Ok(())
320	}

322	/// Reveals (shows and focuses) a Webview panel.
323	async fn RevealWebviewPanel(&self, Handle:String, _ShowOptionsValue:Value) -> Result<(), CommonError> {
324		info!("[WebviewProvider] Revealing WebviewPanel: {}", Handle);
325
326		if let Some(WebviewWindow) = self.ApplicationHandle.get_webview_window(&Handle) {
327			WebviewWindow.show().map_err(|Error| {
328				CommonError::UserInterfaceInteraction { Reason:format!("Failed to show Webview window: {}", Error) }
329			})?;
330
331			WebviewWindow.set_focus().map_err(|Error| {
332				CommonError::UserInterfaceInteraction { Reason:format!("Failed to focus Webview window: {}", Error) }
333			})?;
334
335			// Update visibility state
336			{
337				let mut WebviewGuard = self
338					.ApplicationState
339					.ActiveWebviews
340					.lock()
341					.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
342
343				if let Some(State) = WebviewGuard.get_mut(&Handle) {
344					State.IsVisible = true;
345				}
346			}
347
348			// Emit visibility event
349			self.ApplicationHandle
350				.emit("sky://webview/revealed", json!({ "Handle": Handle }))
351				.map_err(|Error| {
352					CommonError::IPCError { Description:format!("Failed to emit Webview revealed event: {}", Error) }
353				})?;
354		}
355
356		Ok(())
357	}

359	/// Sets Webview options (title, icon, etc.).
360	async fn SetWebviewOptions(&self, Handle:String, OptionsValue:Value) -> Result<(), CommonError> {
361		info!("[WebviewProvider] Setting options for Webview: {}", Handle);
362
363		if let Some(WebviewWindow) = self.ApplicationHandle.get_webview_window(&Handle) {
364			let OptionsMap:HashMap<String, Value> = serde_json::from_value(OptionsValue.clone()).map_err(|Error| {
365				CommonError::SerializationError { Description:format!("Failed to parse Webview options: {}", Error) }
366			})?;
367
368			// Update title
369			if let Some(Title) = OptionsMap.get("title").and_then(|v| v.as_str()) {
370				WebviewWindow.set_title(Title).map_err(|Error| {
371					CommonError::UserInterfaceInteraction { Reason:format!("Failed to set Webview title: {}", Error) }
372				})?;
373
374				// Update state
375				{
376					let mut WebviewGuard = self
377						.ApplicationState
378						.ActiveWebviews
379						.lock()
380						.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
381
382					if let Some(State) = WebviewGuard.get_mut(&Handle) {
383						State.Title = Title.to_string();
384					}
385				}
386			}
387
388			// TODO: Implement icon path setting
389		}
390
391		// Emit options changed event
392		self.ApplicationHandle
393			.emit(
394				"sky://webview/options-changed",
395				json!({ "Handle": Handle, "Options": OptionsValue }),
396			)
397			.map_err(|Error| {
398				CommonError::IPCError { Description:format!("Failed to emit Webview options changed event: {}", Error) }
399			})?;
400
401		Ok(())
402	}

404	/// Sets the HTML content of a Webview.
405	async fn SetWebviewHTML(&self, Handle:String, HTML:String) -> Result<(), CommonError> {
406		debug!("[WebviewProvider] Setting HTML for Webview: {} ({} bytes)", Handle, HTML.len());
407
408		if let Some(WebviewWindow) = self.ApplicationHandle.get_webview_window(&Handle) {
409			WebviewWindow.emit("sky://webview/set-html", HTML).map_err(|Error| {
410				CommonError::IPCError { Description:format!("Failed to set Webview HTML: {}", Error) }
411			})?;
412
413			Ok(())
414		} else {
415			Err(CommonError::WebviewNotFound { Handle })
416		}
417	}

419	/// Posts a message to a Webview with proper error handling.
420	async fn PostMessageToWebview(&self, Handle:String, Message:Value) -> Result<bool, CommonError> {
421		debug!("[WebviewProvider] Posting message to Webview: {}", Handle);
422
423		if let Some(WebviewWindow) = self.ApplicationHandle.get_webview_window(&Handle) {
424			let WebviewMessage = WebviewMessage {
425				MessageIdentifier:Uuid::new_v4().to_string(),
426				MessageType:"request".to_string(),
427				Payload:Message,
428				Source:Some("host".to_string()),
429			};
430
431			WebviewWindow
432				.emit("sky://webview/post-message", WebviewMessage)
433				.map_err(|Error| {
434					CommonError::IPCError { Description:format!("Failed to post message to Webview: {}", Error) }
435				})?;
436
437			debug!("[WebviewProvider] Message sent successfully to Webview: {}", Handle);
438			Ok(true)
439		} else {
440			warn!("[WebviewProvider] Webview not found for message: {}", Handle);
441			Ok(false)
442		}
443	}
