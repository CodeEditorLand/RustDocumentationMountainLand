1//! # ConfigurationProvider (Environment)
2//!
3//! Implements `ConfigurationProvider` and `ConfigurationInspector` traits,
4//! managing all application settings across multiple scopes (Default, User,
5//! Workspace, Folder). It handles the configuration cascade, merging settings
6//! from various sources in the correct precedence order.
7//!
8//! ## RESPONSIBILITIES
9//!
10//! ### 1. Configuration Cascade
11//! - Implement multi-layer configuration hierarchy: Default → User → Workspace
12//!   → Folder
13//! - Apply precedence rules: higher layers override lower layers
14//! - Merge configuration objects from different sources
15//! - Handle configuration inheritance and overrides
16//!
17//! ### 2. Configuration Storage
18//! - Read default settings from resource files
19//! - Load user settings from global storage (`globalStorage.json`)
20//! - Load workspace settings from `.code-workspace` files
21//! - Load folder settings from `.vscode/settings.json`
22//! - Persist configuration changes to disk
23//!
24//! ### 3. Configuration Access
25//! - Provide `GetConfiguration` for retrieving merged settings
26//! - Support nested property access via dot notation (e.g., `"editor.fontSize"`)
27//! - Implement `ConfigurationInspector` for introspection
28//! - Cache configuration for performance
29//!
30//! ### 4. Configuration Updates
31//! - Handle runtime configuration changes
32//! - Notify listeners when configuration updates occur
33//! - Persist changes to appropriate storage layer
34//! - Re-merge configuration after changes
35//!
36//! ## ARCHITECTURAL ROLE
37//!
38//! ConfigurationProvider is the **configuration management core**:
39//!
40//! ```text
41//! Providers ──► ConfigurationProvider ──► MergedConfigurationStateDTO ──► Disk
42//!               │
43//!               └─► Multiple Storage Layers
44//! ```
45//!
46//! ### Position in Mountain
47//! - `Environment` module: Core capability provider
48//! - Implements `CommonLibrary::Configuration::ConfigurationProvider` and
49//!   `ConfigurationInspector`
50//! - Accessible via `Environment.Require<dyn ConfigurationProvider>()`
51//!
52//! ### Configuration Scope Precedence (lowest to highest)
53//! 1. **Default**: Built-in Mountain defaults
54//! 2. **User**: Global user settings (`User/settings.json`)
55//! 3. **Workspace**: Workspace file (`.code-workspace`)
56//! 4. **Folder**: Per-folder settings (`.vscode/settings.json`)
57//! 5. **Workspace-Folder**: Workspace settings for specific folder
58//!
59//! ### Dependencies
60//! - `ApplicationState`: Access to `Configuration` state and storage paths
61//! - `FileSystemReader`: Read configuration files from disk
62//! - `Log`: Configuration change logging
63//!
64//! ### Dependents
65//! - All providers that need configuration values
66//! - `Binary::Main`: Initial configuration setup
67//! - `InitializationData`: Includes configuration in frontend payload
68//! - Command handlers: Read settings to customize behavior
69//!
70//! ## CONFIGURATION MERGE STRATEGY
71//!
72//! Configuration is merged using a **depth-first cascade**:
73//!
74//! 1. Start with default values
75//! 2. Overlay user settings (if exist)
76//! 3. Overlay workspace settings (if exists)
77//! 4. For each folder, overlay folder settings
78//! 5. For workspace-folders, apply folder-specific overrides
79//!
80//! The final result is a single JSON object representing the effective
81//! configuration for the current context.
82//!
83//! ## PROPERTY ACCESS
84//!
85//! - `GetConfiguration(Section)` returns the entire configuration or a
86//!   subsection
87//! - Section uses dot notation: `"editor.fontSize"` or `"typescript.format.enable"`
88//! - Returns `serde_json::Value` which can be queried further
89//! - Missing properties return `Value::Null`
90//!
91//! ## ERROR HANDLING
92//!
93//! - File read errors: `CommonError::FileSystemIO`
94//! - JSON parse errors: `CommonError::SerializationError`
95//! - Invalid section paths: `Value::Null` (no error)
96//! - Write permission errors: `CommonError::FileSystemIO`
97//!
98//! ## PERFORMANCE
99//!
100//! - Configuration is cached in `ApplicationState::Configuration`
101//! - Merging happens on change (not on every read)
102//! - File reads are async via `ApplicationRunTime`
103//! - Consider incremental merging for large configurations (TODO)
104//!
105//! ## VS CODE REFERENCE
106//!
107//! Patterns from VS Code's configuration system:
108//! - `vs/platform/configuration/common/configuration.ts` - Configuration service
109//! - `vs/platform/configuration/common/configurationCache.ts` - Caching
110//! - `vs/platform/configuration/common/configurationLayer.ts` - Layer merging
111//!
112//! ## TODO

131//
132// 1. **Configuration Cascade**: Implements the multi-layer configuration
133//    hierarchy Default → User → Workspace → Folder, with higher precedence
134//    overriding lower.
135//
136// 2. **Configuration Merging**: Performs deep merge of JSON configuration
137//    objects from all scopes to produce the effective configuration.
138//
139// 3. **Configuration Persistence**: Reads and writes settings.json files for
140//    User and Workspace scopes using the FileSystemWriter effect.
141//
142// 4. **Configuration Inspection**: Provides visibility into which scope is
143//    providing each configuration value for debugging and diagnostics.
144//
145// 5. **Extension Configuration Merging**: Collects default configurations from
146//    all installed extensions as part of the Default scope.
147//
148// # Configuration Cascade Order (Highest to Lowest Precedence)
149//
150// 1. Workspace Folder settings (.vscode/settings.json)
151// 2. Workspace settings (workspace root settings.json)
152// 3. User settings (app config dir/settings.json)
153// 4. Extension default configurations (from package.json)
154//
155// # Patterns Borrowed from VSCode
156//
157// - **Configuration Targets**: Mimics VSCode's ConfigurationTarget enum for
158//   specifying which configuration layer to update.
159//
160// - **Deep Merge**: Like VSCode's configuration service, performs recursive
161//   merge of JSON objects instead of shallow replacement.
162//
163// - **Configuration Inspection**: Similar to VSCode's inspect() API, provides
164//   visibility into all configuration sources and their values.
165//
166// - **JSON Editing**: Like VSCode's JSONEditingService, uses queue-based writes
167//   to prevent race conditions during concurrent updates.

212#[async_trait]
213impl ConfigurationProvider for MountainEnvironment {
214	/// Retrieves a configuration value from the cached, merged configuration.
215	async fn GetConfigurationValue(
216		&self,
217
218		Section:Option<String>,
219
220		Overrides:ConfigurationOverridesDTO,
221	) -> Result<Value, CommonError> {
222		debug!("[ConfigurationProvider] Getting configuration for section: {:?}", Section);
223
224		let ConfigurationGuard = self
225			.ApplicationState
226			.Configuration
227			.lock()
228			.map_err(Utility::MapApplicationStateLockErrorToCommonError)?;
229
230		let ConfigurationValue = ConfigurationGuard.GetValue(Section.as_deref());
231
232		// Validate that the configuration value exists
233		if ConfigurationValue.is_null() {
234			warn!("[ConfigurationProvider] Configuration section not found: {:?}", Section);
235		}
236
237		Ok(ConfigurationValue)
238	}
239
240	/// Updates a configuration value in the appropriate `settings.json` file.
241	async fn UpdateConfigurationValue(
242		&self,
243
244		Key:String,
245
246		Value:Value,
247
248		Target:ConfigurationTarget,
249
250		Overrides:ConfigurationOverridesDTO,
251
252		ScopeToLanguage:Option<bool>,
253	) -> Result<(), CommonError> {
254		info!("[ConfigurationProvider] Updating key '{}' in target {:?}", Key, Target);
255
256		let RunTime = self.ApplicationHandle.state::<Arc<MountainRunTime>>().inner().clone();
257
258		let ConfigPath:PathBuf = match Target {
259			ConfigurationTarget::User => {
260				self.ApplicationHandle
261					.path()
262					.app_config_dir()
263					.map(|p| p.join("settings.json"))
264					.map_err(|Error| {
265						CommonError::ConfigurationLoad {
266							Description:format!("Could not resolve user config path: {}", Error),
267						}
268					})?
269			},
270
271			ConfigurationTarget::Workspace => {
272				self.ApplicationState
273					.WorkspaceConfigurationPath
274					.lock()
275					.map_err(Utility::MapApplicationStateLockErrorToCommonError)?
276					.clone()
277					.ok_or_else(|| {
278						CommonError::ConfigurationLoad { Description:"No workspace configuration path set".into() }
279					})?
280			},
281
282			_ => {
283				warn!("[ConfigurationProvider] Unsupported configuration target: {:?}", Target);
284
285				return Err(CommonError::NotImplemented {
286					FeatureName:"This configuration target is not supported".into(),
287				});
288			},
289		};
290
291		// Read the file, modify it, and write it back.
292		let Bytes = RunTime.Run(ReadFile(ConfigPath.clone())).await.unwrap_or_default();
293
294		let mut CurrentConfig:Value = serde_json::from_slice(&Bytes).unwrap_or_else(|_| Value::Object(Map::new()));
295
296		if let Value::Object(Map) = &mut CurrentConfig {
297			if Value.is_null() {
298				Map.remove(&Key);
299				info!("[ConfigurationProvider] Removed configuration key '{}'", Key);
300			} else {
301				Map.insert(Key.clone(), Value.clone());
302				info!("[ConfigurationProvider] Updated configuration key '{}'", Key);
303			}
304		}
305
306		let ContentBytes = serde_json::to_vec_pretty(&CurrentConfig)?;
307
308		RunTime
309			.Run(WriteFileBytes(ConfigPath.clone(), ContentBytes, true, true))
310			.await?;
311
312		// Re-merge all configurations to update the live state.
313		InitializeAndMergeConfigurations(self).await?;
314
315		Ok(())
316	}
317}

319#[async_trait]
320impl ConfigurationInspector for MountainEnvironment {
321	/// Inspects a configuration key to get its value from all relevant scopes.
322	async fn InspectConfigurationValue(
323		&self,
324
325		Key:String,
326
327		Overrides:ConfigurationOverridesDTO,
328	) -> Result<Option<InspectResultDataDTO>, CommonError> {
329		info!("[ConfigurationProvider] Inspecting key: {}", Key);
330
331		let UserSettingsPath = self
332			.ApplicationHandle
333			.path()
334			.app_config_dir()
335			.map(|p| p.join("settings.json"))
336			.ok();
337
338		let WorkspaceSettingsPath = self
339			.ApplicationState
340			.WorkspaceConfigurationPath
341			.lock()
342			.map_err(Utility::MapApplicationStateLockErrorToCommonError)?
343			.clone();
344
345		// Read each configuration layer individually.
346		let DefaultConfig = CollectDefaultConfigurations(&self.ApplicationState)?;
347
348		let UserConfig = ReadAndParseConfigurationFile(self, &UserSettingsPath).await?;
349
350		let WorkspaceConfig = ReadAndParseConfigurationFile(self, &WorkspaceSettingsPath).await?;
351
352		let GetValueFromDotPath =
353			|Node:&Value, Path:&str| -> Option<Value> { Path.split('.').try_fold(Node, |n, k| n.get(k)).cloned() };
354
355		let mut ResultDTO = InspectResultDataDTO::default();
356
357		ResultDTO.DefaultValue = GetValueFromDotPath(&DefaultConfig, &Key);
358
359		ResultDTO.UserValue = GetValueFromDotPath(&UserConfig, &Key);
360
361		ResultDTO.WorkspaceValue = GetValueFromDotPath(&WorkspaceConfig, &Key);
362
363		// Determine the final effective value based on the correct cascade order.
364		ResultDTO.EffectiveValue = ResultDTO
365			.WorkspaceValue
366			.clone()
367			.or_else(|| ResultDTO.UserValue.clone())
368			.or_else(|| ResultDTO.DefaultValue.clone());
369
370		if ResultDTO.EffectiveValue.is_some() { Ok(Some(ResultDTO)) } else { Ok(None) }
371	}
372}

374/// An internal helper to read and parse a single JSON configuration file.
375async fn ReadAndParseConfigurationFile(
376	Environment:&MountainEnvironment,
377
378	Path:&Option<PathBuf>,
379) -> Result<Value, CommonError> {
380	if let Some(p) = Path {
381		let RunTime = Environment.ApplicationHandle.state::<Arc<MountainRunTime>>().inner().clone();
382
383		if let Ok(Bytes) = RunTime.Run(ReadFile(p.clone())).await {
384			return Ok(serde_json::from_slice(&Bytes).unwrap_or(Value::Object(Map::new())));
385		}
386	}
387
388	Ok(Value::Object(Map::new()))
389}

391/// Logic to load and merge all configuration files into the effective
392/// configuration stored in `ApplicationState`.
393pub async fn InitializeAndMergeConfigurations(Environment:&MountainEnvironment) -> Result<(), CommonError> {
394	info!("[ConfigurationProvider] Re-initializing and merging all configurations...");
395
396	let DefaultConfig = CollectDefaultConfigurations(&Environment.ApplicationState)?;
397
398	let UserSettingsPath = Environment
399		.ApplicationHandle
400		.path()
401		.app_config_dir()
402		.map(|p| p.join("settings.json"))
403		.ok();
404
405	let WorkspaceSettingsPath = Environment
406		.ApplicationState
407		.WorkspaceConfigurationPath
408		.lock()
409		.map_err(Utility::MapApplicationStateLockErrorToCommonError)?
410		.clone();
411
412	let UserConfig = ReadAndParseConfigurationFile(Environment, &UserSettingsPath).await?;
413
414	let WorkspaceConfig = ReadAndParseConfigurationFile(Environment, &WorkspaceSettingsPath).await?;
415
416	// A true deep merge is required here. The merge order matches the cascade:
417	// Default (base) → User (overrides default) → Workspace (overrides user)
418	let mut Merged = DefaultConfig.as_object().cloned().unwrap_or_default();
419
420	if let Some(UserMap) = UserConfig.as_object() {
421		for (Key, Value) in UserMap {
422			// Deep merge nested objects, shallow merge at root level
423			if Value.is_object() && Merged.get(Key.as_str()).is_some_and(|v| v.is_object()) {
424				if let (Some(UserValue), Some(BaseValue)) =
425					(Value.as_object(), Merged.get(Key.as_str()).and_then(|v| v.as_object()))
426				{
427					for (InnerKey, InnerValue) in UserValue {
428						Merged.get_mut(Key.as_str()).and_then(|v| v.as_object_mut()).map(|m| {
429							m.insert(InnerKey.clone(), InnerValue.clone());
430						});
431					}
432				}
433			} else {
434				Merged.insert(Key.clone(), Value.clone());
435			}
436		}
437	}
438
439	if let Some(WorkspaceMap) = WorkspaceConfig.as_object() {
440		for (Key, Value) in WorkspaceMap {
441			if Value.is_object() && Merged.get(Key.as_str()).is_some_and(|v| v.is_object()) {
442				if let (Some(WorkspaceValue), Some(BaseValue)) =
443					(Value.as_object(), Merged.get(Key.as_str()).and_then(|v| v.as_object()))
444				{
445					for (InnerKey, InnerValue) in WorkspaceValue {
446						Merged.get_mut(Key.as_str()).and_then(|v| v.as_object_mut()).map(|m| {
447							m.insert(InnerKey.clone(), InnerValue.clone());
448						});
449					}
450				}
451			} else {
452				Merged.insert(Key.clone(), Value.clone());
453			}
454		}
455	}
456
457	let ConfigurationSize = Merged.len();
458	let FinalConfig = MergedConfigurationStateDTO::Create(Value::Object(Merged));
459
460	*Environment
461		.ApplicationState
462		.Configuration
463		.lock()
464		.map_err(Utility::MapApplicationStateLockErrorToCommonError)? = FinalConfig;
465
466	info!(
467		"[ConfigurationProvider] Configuration merged successfully with {} top-level keys.",
468		ConfigurationSize
469	);
470
471	Ok(())
