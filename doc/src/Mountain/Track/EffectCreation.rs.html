3// # Central Routing Table for Mountain Application
4//
5// ## Responsibilities
6//
7// This module serves as the **central routing table** for the entire Mountain
8// backend. Its primary responsibilities are:
9//
10// ### 1. Command-to-Effect Mapping
11// - Map string-based command and RPC method names to their strongly-typed
12//   effect constructors from the `Common` crate
13// - Ensure all commands from Wind (frontend) and Cocoon (sidecar) have
14//   corresponding effects
15// - Provide default/error handling for unknown commands
16// - Create a runnable, type-erased `MappedEffect` for each request
17//
18// ### 2. Effect System Integration
19// - Transform declarative ActionEffects into executable closures
20// - Ensure proper parameter deserialization and validation
21// - Handle type-safe effect creation with comprehensive error context
22// - Support both direct provider calls and effect-based execution
23//
24// ### 3. Error Handling and Validation
25// - Validate all input parameters before effect creation
26// - Provide detailed error messages for failed mappings
27// - Handle serialization/deserialization errors gracefully
28// - Support parameter defaults and optionals
29//
30// ## Architectural Role
31//
32// EffectCreation is the **routing layer** that sits between:
33//
34// DispatchLogic (Router) ──► EffectCreation (Mapper) ──► ApplicationRunTime
35// (Executor)
36//
37// ### Design Patterns:
38// 1. **Command Pattern**: Each command is mapped to a specific effect
39// 2. **Factory Pattern**: The CreateEffectForRequest function creates effects
40// 3. **Strategy Pattern**: Direct provider calls vs effect-based execution
41//
42// ### VS Code Reference:
43// This module borrows from VS Code's command registration and dispatch
44// system in `vs/workbench/services/extensions/common/extensions.ts`
45// and `vs/platform/commands/common/commands.ts`. Key concepts:
46// - Command ID → Handler mapping
47// - Type-safe parameter passing
48// - Async execution with proper error propagation
49//
50// ## Key Components
51//
52// ### CreateEffectForRequest
53// The primary entry point that maps method names to effects. Returns a
54// `MappedEffect` which is a boxed, async closure that can be executed by
55// the ApplicationRunTime.
56//
57// ### Direct Provider Calls
58// For performance-critical operations, we bypass the effect system and call
59// providers directly. This is done for:
60// - Configuration inspection/updates (high frequency)
61// - Diagnostics (real-time updates)
62// - Language features (interactive editing)
63// - Terminal operations (direct user input)
64//
65// ### Effect-Based Handlers
66// Most operations go through the effect system for:
67// - Consistency and maintainability
68// - Declarative semantics
69// - Easier testing and mocking
70// - Better error handling
71//

231/// A type alias for a boxed, runnable effect. This is the "type-erased" unit of
232/// work that the dispatch logic can execute.
233pub type MappedEffect =
234	Box<dyn FnOnce(Arc<MountainRunTime>) -> Pin<Box<dyn Future<Output = Result<Value, String>> + Send>> + Send>;
235
236/// A helper macro to reduce boilerplate when getting and deserializing
237/// parameters from a JSON array.
238macro_rules! Parameter {
239	($Parameter:expr, $Current:expr, $Type:ty) => {
240		from_value::<$Type>(
241			$Parameter
242				.get($Current)
243				.cloned()
244				.ok_or_else(|| format!("Missing parameter at index {}", $Current))?,
245		)
246		.map_err(|Error| format!("Invalid parameter at index {}: {}", $Current, Error))
247	};
248}

250/// A helper that takes a specific `ActionEffect`, boxes it, and returns a
251/// closure that can be run by the dispatcher. This is used for effects that
252/// follow the declarative pattern.
253fn Map<C, O, E>(Effect:ActionEffect<Arc<C>, E, O>) -> MappedEffect
254where
255	C: ?Sized + Send + Sync + 'static,
256	O: serde::Serialize + Send + Sync + 'static,
257	E: Into<CommonError> + From<CommonError> + Send + Sync + 'static,
258	MountainEnvironment: Requires<C>, {
259	Box::new(move |RunTime:Arc<MountainRunTime>| {
260		Box::pin(async move {
261			let Result = RunTime.Run(Effect).await;
262
263			match Result {
264				Ok(Output) => serde_json::to_value(Output).map_err(|Error| format!("Serialization failed: {}", Error)),
265
266				Err(Error) => {
267					let CommonError:CommonError = Error.into();
268
269					Err(CommonError.to_string())
270				},
271			}
272		})
273	})
274}
