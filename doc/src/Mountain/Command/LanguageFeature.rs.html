1//! # LanguageFeature (Command)
2//!
3//! RESPONSIBILITIES:
4//! - Defines Tauri command handlers for language feature requests from Sky
5//!   frontend
6//! - Bridges Monaco Editor language requests to
7//!   [`LanguageFeatureProviderRegistry`]
8//! - Provides type-safe parameter handling and validation for LSP features
9//! - Implements hover, code actions, document highlights, completions,
10//!   definition, references
11//! - Uses generic `InvokeProvider` helper to reduce boilerplate
12//!
13//! ARCHITECTURAL ROLE:
14//! - Command layer that exposes language features via Tauri IPC (`#[command]`)
15//! - Delegates to Environment's
16//!   [`LanguageFeatureProvider`](crate::Environment::LanguageFeatureProvider)
17//!   via DI with `Require()` trait
18//! - Translates between frontend JSON parameters and Rust DTO types
19//! - Error strings returned directly to frontend for display
20//!
21//! COMMAND REFERENCE (Tauri IPC):
22//! - [`MountainProvideHover`](crate::Command::LanguageFeature::MountainProvideHover):
23//!   Show hover information at cursor position
24//! - [`MountainProvideCodeActions`](crate::Command::LanguageFeature::MountainProvideCodeActions):
25//!   Get quick fixes and refactorings for a code range
26//! - [`MountainProvideDocumentHighlights`](crate::Command::LanguageFeature::MountainProvideDocumentHighlights):
27//!   Find symbol occurrences in document
28//! - [`MountainProvideCompletions`](crate::Command::LanguageFeature::MountainProvideCompletions):
29//!   Get code completion suggestions with context
30//! - [`MountainProvideDefinition`](crate::Command::LanguageFeature::MountainProvideDefinition):
31//!   Jump to symbol definition location
32//! - [`MountainProvideReferences`](crate::Command::LanguageFeature::MountainProvideReferences):
33//!   Find all references to a symbol
34//!
35//! ERROR HANDLING:
36//! - Returns `Result<Value, String>` where errors sent directly to frontend
37//! - Validates URI non-empty and position format (line/character numbers)
38//! - JSON serialization errors converted to strings
39//! - Provider errors (CommonError) converted to strings via `map_err(|Error|
40//!   Error.to_string())`
41//!
42//! PERFORMANCE:
43//! - Each command is async and non-blocking
44//! - Provider lookup is O(1) via `Require()` from DI container
45//! - URI parsing and DTO deserialization adds minimal overhead
46//!
47//! VS CODE REFERENCE:
48//! - `vs/workbench/api/common/extHostLanguageFeatures.ts` - ext host language
49//!   features API
50//! - `vs/workbench/services/languageFeatures/common/languageFeaturesService.ts`
51//!   - service layer
52//! - `vs/workbench/contrib/hover/browser/hover.ts` - hover implementation
53//! - `vs/workbench/contrib/completion/browser/completion.ts` - completion
54//!   widget
55//! - `vs/workbench/contrib/definition/browser/definition.ts` - go to definition
56//! - `vs/workbench/contrib/references/browser/references.ts` - find references
57//!
58//! TODO:
59//! - Implement more language features: document symbols, formatting, rename,
60//!   signature help
61//! - Add cancellation token support for long-running operations
62//! - Implement request deduplication for identical concurrent requests
63//! - Add request caching for repeated symbol lookups
64//! - Support workspace symbol search
65//! - Add semantic tokens for syntax highlighting
66//! - Implement code lens provider
67//! - Add inlay hints support
68//! - Support linked editing range
69//! - Add call hierarchy and type hierarchy
70//! - Implement document color and color presentation
71//! - Add folding range provider
72//! - Support selection range provider
73//!
74//! MODULE STRUCTURE:
75//! - [`validation.rs`](validation.rs) - request validation helper
76//! - [`invoke_provider.rs`](invoke_provider.rs) - generic provider invoker
77//! - Individual command modules for each language feature (containing impls
78//!   only)

105/// Provides hover information at cursor position
106#[command]
107pub async fn MountainProvideHover(
108	application_handle:AppHandle<Wry>,
109	uri:String,
110	position:Value,
111) -> Result<Value, String> {
112	debug!("[Language Feature] Providing hover for: {} at {:?}", uri, position);
113	hover::provide_hover_impl(application_handle, uri, position).await
114}
