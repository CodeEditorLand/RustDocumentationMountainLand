1//! # Keybinding (Command)
2//!
3//! RESPONSIBILITIES:
4//! - Defines Tauri command handlers for keybinding operations from Sky frontend
5//! - Bridges keybinding requests to [`KeybindingProvider`](CommonLibrary::Keybinding::KeybindingProvider)
6//! - Handles keybinding resolution, conflict detection, and extension registration
7//! - Manages user keybinding preferences and extension contributions
8//!
9//! ARCHITECTURAL ROLE:
10//! - Command module exposing keybinding functionality via Tauri IPC (`#[command]`)
11//! - Delegates to Environment's [`KeybindingProvider`](crate::Environment::KeybindingProvider)
12//!   via DI with `Require()` trait
13//! - Acts as thin façade layer; all logic resides in provider implementation
14//!
15//! COMMAND REFERENCE (Tauri IPC):
16//! - [`GetResolvedKeybinding`](crate::Command::Keybinding::GetResolvedKeybinding):
17//!   Get the final resolved keybindings after merging all sources
18//! - [`GetUserKeybindings`](crate::Command::Keybinding::GetUserKeybindings):
19//!   Retrieve user-defined keybinding overrides (stub)
20//! - [`RegisterExtensionKeybindings`](crate::Command::Keybinding::RegisterExtensionKeybindings):
21//!   Register keybindings contributed by an extension (stub)
22//! - [`UnregisterExtensionKeybindings`](crate::Command::Keybinding::UnregisterExtensionKeybindings):
23//!   Remove keybindings for an extension (stub)
24//! - [`CheckKeybindingConflicts`](crate::Command::Keybinding::CheckKeybindingConflicts):
25//!   Check if a keybinding conflicts with existing ones (stub)
26//!
27//! ERROR HANDLING:
28//! - Returns `Result<Value, String>` where errors sent to frontend
29//! - Provider errors converted to strings via `map_err(|Error| Error.to_string())`
30//! - TODO: Implement proper conflict detection and user keybinding storage
31//!
32//! PERFORMANCE:
33//! - All commands are async but currently mostly stubs
34//! - Resolved keybindings query should be O(1) from cached state (TODO)
35//!
36//! VS CODE REFERENCE:
37//! - `vs/workbench/services/keybinding/browser/keybindingService.ts` - keybinding service
38//! - `vs/platform/keybinding/common/keybindingResolver.ts` - keybinding resolution algorithm
39//! - `vs/workbench/services/keybinding/common/keybinding.ts` - keybinding data models
40//! - `vs/workbench/common/keybindings.ts` - keybinding registry and conflict detection
41//!
42//! TODO:
43//! - Implement keybinding resolution with proper weighting (user > extension > default)
44//! - Add keybinding conflict detection across all registered bindings
45//! - Persist user keybinding overrides to ApplicationState
46//! - Implement extension keybinding registration/unregistration
47//! - Support keybinding context conditions (when clauses)
48//! - Add command argument handling in keybindings
49//! - Implement chord keybindings (multi-stroke sequences)
50//! - Add keybinding export/import functionality
51//! - Support platform-specific keybindings (Windows, macOS, Linux)
52//! - Implement keybinding search and discovery UI
53//! - Add keybinding documentation tooltips
54//! - Support macro recording and playback via keybindings
55//!
56//! MODULE CONTENTS:
57//! - Tauri command functions (all `#[command] pub async fn`):
58//!   - `GetResolvedKeybinding` - query final resolved keybindings
59//!   - `GetUserKeybindings` - get user overrides (stub)
60//!   - `RegisterExtensionKeybindings` - register extension bindings (stub)
61//!   - `UnregisterExtensionKeybindings` - unregister extension bindings (stub)
62//!   - `CheckKeybindingConflicts` - detect conflicts (stub)

72#[command]
73pub async fn GetResolvedKeybinding(ApplicationHandle:AppHandle<Wry>) -> Result<Value, String> {
74	log::debug!("[Keybinding Command] Getting resolved keybindings for UI.");
75
76	let RunTime = ApplicationHandle.state::<Arc<MountainRunTime>>().inner().clone();
77
78	let Provider:Arc<dyn KeybindingProvider> = RunTime.Environment.Require();
79
80	Provider.GetResolvedKeybinding().await.map_err(|Error| Error.to_string())
81}
