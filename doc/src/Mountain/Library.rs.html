3//! # Library
4//!
5//! Library root module for the Mountain application, declaring all subsystem
6//! modules and providing the main entry point for the Tauri desktop framework.
7//!
8//! ## RESPONSIBILITIES
9//!
10//! ### Module Organization
11//! - Declare and export all Mountain subsystem modules
12//! - Provide clean module boundaries and visibility rules
13//! - Enable dependency management between components
14//! - Support both library and binary builds
15//!
16//! ### Entry Point
17//! - Provide mobile build entry point required by Tauri
18//! - Delegate to Binary module for main application logic
19//!
20//! ## ARCHITECTURAL ROLE
21//!
22//! ### Position in Mountain
23//! - Library root for the Mountain crate
24//! - Central module declaration point
25//! - Provides module visibility control
26//!
27//! ### Dependencies
28//! - Common: Shared infrastructure
29//! - Tauri: Desktop framework integration
30//!
31//! ### Dependents
32//! - Binary: Uses all modules for application initialization
33//!
34//! ## MODULE STRUCTURE
35//!
36//! ### Core Infrastructure
37//! - ApplicationState: Centralized state management
38//! - Environment: Capability provider and dependency injection
39//! - RunTime: Effect execution engine
40//!
41//! ### Communication
42//! - IPC: Inter-process communication
43//! - Air: AI/integration service client
44//! - Vine: gRPC inter-service communication
45//!
46//! ### Service Management
47//! - ProcessManagement: Sidecar process lifecycle
48//! - FileSystem: File system operations
49//! - ExtensionManagement: Extension discovery
50//!
51//! ### Commands & Features
52//! - Command: Native command implementations
53//! - Track: Command tracking and dispatch
54//! - Workspace: Workspace file parsing
55//!
56//! ### Entry Point
57//! - Binary: Main application entry point
