Initialization-domain handlers for CocoonService. CancelOperation::Fn, InitialHandshake::Fn, InitExtensionHost::Fn.

Modules§

CancelOperation
Cancel an in-flight Mountain-originated operation by request id. Looks up the cancellation token in Service.ActiveOperations and fires it.
InitExtensionHost
Mountain → Cocoon initialization payload (workspace folders + configuration). Stores parsed folders into ApplicationState.Workspace so the rest of the boot path sees them.
InitialHandshake
Cocoon → Mountain ready ping. No payload; Mountain replies with the init-extension-host data via InitExtensionHost::Fn.
